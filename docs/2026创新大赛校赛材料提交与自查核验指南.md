### 一、 校赛评审模式特征与专家审阅逻辑 (Desk Review Strategy)

华南师范大学校赛（及院级初赛）采用 **“案头网评 / 专家盲审”** 机制，**不设置现场路演与答辩环节**。

在网评阶段，校内外评审专家通常在系统内用 **3 ~ 5 分钟** 快速翻阅申报材料并打分。评委的审阅路径非常固定：

```
┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                 校赛网评专家 3 分钟极速审阅路径                                  │
├──────────────────────────┬─────────────────────────────┬────────────────────────────────────────┤
│  1. 翻阅《附件3申报表》   │  2. 快速浏览《网评展示PPT》 │  3. 抽查《实测研报与白皮书附件》       │
│  (30~60秒)               │  (1~2分钟)                  │  (30~60秒)                             │
│  • 项目名称与达观命题对齐 │  • 架构图是否清晰漂亮       │  • 是否有真实的实盘/回测数据           │
│  • 项目简介与团队分工     │  • 痛点与核心技术创新       │  • 3 份研报图表是否专业工整            │
│  • 10 项达标指标是否超额 │  • 实测收益与回撤控制曲线   │  • 202 股票大底座与学术溯源背书        │
└──────────────────────────┴─────────────────────────────┴────────────────────────────────────────┘
```
