## 🎯 核心算法一览

### 第 1 步: NALE 因子计算
```
每天对每个期货合约计算:
  - PC1-PC10 (主成分)
  - alpha_nale [-1, 1]
```

### 第 2 步: 板块评分聚合
```
4 个板块的评分 = 该板块所有合约 NALE 的平均值

比如: AGRI = avg(M_nale, OI_nale, RM_nale)
```

### 第 3 步: 日频轮动决策
```
简单规则:
  IF 当前板块评分 < -0.2 THEN
    选择评分最高的板块作为目标
    执行轮动
  冷却期: 轮动后 3 天不再轮动
```

### 第 4 步: 仓位管理
```
卖出旧板块的所有合约
买入新板块的主力合约
记录交易成本和滑点
```
