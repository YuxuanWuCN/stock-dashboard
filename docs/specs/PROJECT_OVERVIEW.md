## 📊 项目全景

### 核心能力

你将拥有一个系统，它能够：

1. **实时监控板块情绪**
   - 从个股新闻 → 聚合到板块
   - 计算板块情绪分数、趋势、波动率
   - 识别下沉信号

2. **自动做轮动决策**
   - 当板块下沉时自动识别
   - 选择最佳目标板块
   - LLM 解释决策理由

3. **安全执行切换**
   - 渐进式 3 日完成切换
   - 成本 ≤ 1%
   - 风险控制机制

4. **可解释、可追溯**
   - 每个决策都有理由
   - 完整的决策历史
   - 监控面板

### 改进对标

| 对标项 | 参考论文 | 本项目实现 |
|--------|----------|-----------|
| 情绪识别 | FinSentLLM v2024 | ✓ Multi-LLM 聚合 |
| 板块轮动 | Sector Rotation TSX 2025 | ✓ 动态阈值 + LLM |
| RL 决策 | Language Model Guided RL | ✓ LLM 辅助量化决策 |

## 🚨 关键风险与应对

### 风险 1: LLM 决策一致性差

**影响**: 系统不稳定，无法部署  
**应对方案**：
1. 降低 temperature 到 0.2（确定性）
2. 固定随机种子
3. 量化指标为主，LLM 为辅
4. 加强单元测试

### 风险 2: 回测夏普比率达不到 1.2

**影响**: 系统没有显著优势  
**应对方案**：
1. 优化决策阈值
2. 调整轮动频率
3. 引入其他因子
4. 考虑多策略融合

### 风险 3: 频繁轮动导致成本过高

**影响**: 回测理想，实盘赔钱  
**应对方案**：
1. 严格的冷却期 (7 日)
2. 最短持仓期 (10 日)
3. 成本提高 0.5% → 1% 模拟
4. 每月轮动次数限制 (≤ 2 次)

### 风险 4: 数据延迟导致决策滞后

**影响**: 错过最佳切换时机  
**应对方案**：
1. 多数据源（新闻、社交、研报）
2. 增加数据更新频率
3. 实时告警机制
4. 数据新鲜度检查
