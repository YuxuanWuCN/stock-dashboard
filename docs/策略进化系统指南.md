# 策略进化系统 - 完整指南

**理念**: 每周选出最佳策略 → 深度分析 → 生成衍生变体 → A/B测试 → 保留优秀基因 → 持续进化

---

## 🧬 系统架构

### 核心循环
```
第1周:
  运行 6 个基础组合 → 周日分析 → 激进组合胜出
  → 生成 3 个激进衍生策略

第2周:
  运行 6 个基础 + 3 个激进衍生（共9个）
  → 周日分析 → 激进增强版胜出
  → 生成 3 个激进增强衍生策略
  → 淘汰表现差的激进衍生策略

第3周:
  运行 6 个基础 + 最好的激进增强衍生（共9个）
  → 持续进化...
```

### 三层架构
```
层级 1: 6个基础策略（永久运行，作为基准）
  - 激进、稳健、蓝筹、防御、全球、科技

层级 2: 冠军衍生策略（每周生成3个）
  - 基于上周冠军微调参数
  - 测试期 7 天

层级 3: 历史最佳策略（累计冠军）
  - 如果衍生策略连续2周胜出，升级为永久策略
  - 替换表现最差的基础策略
```

## 📊 评估指标

### 综合得分公式
```python
得分 = 累计收益 × 0.4           # 40% 权重
     + 夏普比率 × 10 × 0.3      # 30% 权重
     + 胜率 × 0.2                # 20% 权重
     - 最大回撤 × 0.1            # 10% 权重（惩罚）
```

### 为什么这样设计？
- **累计收益**: 最直观，但可能靠运气
- **夏普比率**: 风险调整后收益，更科学
- **胜率**: 稳定性指标
- **最大回撤**: 风控指标，避免暴涨暴跌

## 🔬 衍生策略类型

### 1. 激进组合的衍生
当激进组合获胜时，生成：
```
衍生1: 激进增强版
  - Top 6（原 Top 8）
  - 动量权重 × 2
  - 更激进，追求更高收益

衍生2: 激进稳健版
  - Top 10（原 Top 8）
  - 加入风险过滤（<60分）
  - 降低波动

衍生3: 激进动量版
  - 纯动量驱动
  - 忽略预测概率
  - 只看20日涨幅
```

### 2. 稳健组合的衍生
当稳健组合获胜时，生成：
```
衍生1: 稳健严格版
  - 风险 < 30（原 < 40）
  - 概率 > 70%（原 > 60%）
  - 更保守

衍生2: 稳健宽松版
  - 风险 < 50
  - 概率 > 55%
  - 增加候选股票数

衍生3: 稳健平衡版
  - 仓位 90%（原 80%）
  - 持仓 8 只（原 6 只）
  - 提高资金利用率
```

### 3. 固定池组合的衍生（蓝筹/防御/科技）
```
衍生1: 精选版
  - Top 5（原 Top 10）
  - 集中持仓

衍生2: 加权版
  - 按分数加权（原等权）
  - 高分股票更多资金

衍生3: 动量版
  - 优先20日涨幅高的
  - 池内动态调整
```

### 4. 全球组合的衍生
```
衍生1: 美股偏重
  - A股2 + 港股1 + 美股5 + 韩股2
  - 赌美股强势

衍生2: A股偏重
  - A股5 + 港股2 + 美股2 + 韩股1
  - 赌A股强势

衍生3: 极致平衡
  - 每个市场各3只
  - 绝对分散
```

## ⚠️  注意事项

### 1. 过拟合风险
**问题**: 衍生策略可能过度拟合历史数据

**应对**:
- 测试期至少 7 天
- 对比基准（等权）
- 保留基础策略作为对照组

### 2. 市场环境变化
**问题**: 本周冠军可能因为市场风格（牛市/熊市）

**应对**:
- 分析"为什么赢"，不只看"赢了"
- 核心持仓分析
- 预测准确率分析

### 3. 策略爆炸
**问题**: 衍生策略越来越多

**应对**:
- 每周最多保留 3 个衍生策略
- 连续 2 周表现差的自动淘汰
- 总运行策略数控制在 9 个以内
