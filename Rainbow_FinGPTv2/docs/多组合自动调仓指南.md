## 🔄 每日自动调仓流程

### 执行顺序（已优化）
```
每天 18:00 运行 tools/daily_local.ps1：

1. 抓取数据 → 生成排行榜
2. 策略选股 + 激进扫描
3. 明日重点关注 AI 总结
4. ✅ 先记录今日绩效（使用当天持仓）
5. ✅ 所有组合自动调仓（为明天选股）
6. 全池等权基准 + 组合清单
7. FinGPT 校准检查（≥3天触发）
8. Git 提交推送
```

### 关键逻辑
- **今日绩效** = 今日持仓 × 今日涨跌
- **明日持仓** = 基于最新数据的调仓结果
- **历史可追溯** = 每次调仓都备份旧配置

## ⚠️  风险提示

### 1. 高频交易成本
**问题**: 每日调仓会产生大量交易成本
- 佣金: 万分之 2.5
- 印花税: 千分之 1（卖出）
- 滑点: 0.5-1%

**应对**: 
- 模拟盘暂不扣除交易成本
- 校准系统会评估换手率
- 未来可加入最小换手阈值（如 >20% 才调仓）

### 2. 过拟合风险
**问题**: 基于历史数据的选股可能过拟合

**应对**:
- 校准系统会监控对齐率
- 分市场、分行业验证
- 长期跟踪（≥30天）

### 3. 数据质量
**问题**: 第三方数据源可能滞后或错误

**应对**:
- 已有 stale 标记机制
- 多源备份（Sina, Eastmoney, Tencent）
- 异常检测（涨跌幅 >20% 需人工确认）
