# 激进组合自动调仓功能说明

## 📋 功能概述

激进组合现在支持**每日自动调仓**，根据全库扫描结果动态更新持仓，追求最大收益。

---

## 🔄 调仓策略

### 选股逻辑
- **激进分计算**：`激进分 = 5日上涨概率×0.4 + 3日上涨概率×0.3 + 20日动量×0.75`
- **持仓数量**：Top 8 只股票
- **仓位配置**：等权配置，每只 12.5%，满仓（0% 现金）

### 调仓频率
- **每日收盘后自动调仓**（集成在 `daily_local.ps1` 中）
- **调仓时机**：激进扫描 → 自动调仓 → 记录绩效

---

## 🚀 使用方法

### 方法 1: 每日自动调仓（推荐）

已集成到每日任务中，无需手动操作：

```powershell
# 每天 18:00 自动运行
powershell -NoProfile -ExecutionPolicy Bypass -File tools\daily_local.ps1
```

**执行顺序**：
1. 抓取数据 → 生成排行榜
2. 策略选股 + 激进扫描
3. **🆕 自动调仓**（更新 portfolio_aggressive.json）
4. 记录绩效（所有组合，包括激进组合）

### 方法 2: 手动调仓

```bash
# 预览调仓（不实际修改）
python tools/rebalance_aggressive.py --dry-run

# 实际调仓
python tools/rebalance_aggressive.py

# 自定义持仓数量（默认 8 只）
python tools/rebalance_aggressive.py --top 10
```

## 📈 对比：自动调仓 vs 固定持仓

| 特性 | 激进组合（自动调仓） | 稳健组合（固定持仓） |
|------|---------------------|---------------------|
| 调仓频率 | 每日 | 不调仓 |
| 持仓数量 | 8 只（等权） | 6 只（手动配置） |
| 选股标准 | 激进分 Top 8 | 人工选择 |
| 现金比例 | 0%（满仓） | 20% |
| 风险等级 | 高 | 低 |
| 交易成本 | 高（频繁调仓） | 低 |

---

## ⚠️  风险提示

### 1. 高频交易成本
- 每日调仓会产生**大量交易成本**（佣金、印花税、冲击成本）
- 实盘交易时需考虑：
  - 佣金：万分之 2.5
  - 印花税：千分之 1（卖出）
  - 滑点：可能 0.5-1%

### 2. 过拟合风险
- 基于历史数据的激进分可能过拟合
- 市场环境变化时策略可能失效

### 3. 集中度风险
- 满仓 8 只，波动率较高
- 单只股票暴跌影响大

## 🔧 高级配置

### 调整持仓数量

编辑 `tools/rebalance_aggressive.py`：
```python
# 第 131 行
parser.add_argument('--top', type=int, default=8, help='选择 Top N 只股票（默认8）')
```

或运行时指定：
```bash
python tools/rebalance_aggressive.py --top 12
```

### 调整权重配置

如果不想等权，可以修改 `build_portfolio` 函数：
```python
# 按激进分加权（而非等权）
total_score = sum(s['aggressive_score'] for s in selected_stocks)
for stock in selected_stocks:
    pct = (stock['aggressive_score'] / total_score) * 100
    # ...
```

### 关闭自动调仓

编辑 `tools/daily_local.ps1`，注释掉：
```powershell
# & $py tools\rebalance_aggressive.py *>> $logFile
```

## 🎯 预期效果

### 理想情况
- 激进组合 > 等权基准 > 稳健组合
- 捕捉短期趋势和动量

### 现实情况
- 可能因为交易成本、过拟合、市场波动导致跑输基准
- 需要**长期数据（≥30天）**才能评估策略有效性

## 💡 优化建议

1. **降低调仓频率**：改为每周一次（减少交易成本）
2. **设置换手阈值**：只有激进分变化 >5% 才调仓
3. **保留核心持仓**：Top 5 锁定，只调整后 3 只
4. **加入止损机制**：单只跌幅 >8% 强制剔除
5. **行业分散**：限制单个行业最多 3 只
