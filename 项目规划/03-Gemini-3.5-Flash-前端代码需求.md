# 前端代码需求（v1.0 更新版）

## 1. 任务目标

纯静态看板前端，读取后端生成的静态 JSON 展示，不在浏览器中计算核心评分，不调用大语言模型，不连接证券账户。页面面向金融初学者：结论快速可读，依据可展开研究。

## 2. 技术约束

- 纯静态 HTML + CSS + JavaScript（原生，无框架），托管于 GitHub Pages（`docs/`）
- 修改 `docs/index.html`、`docs/assets/app.js`、`docs/assets/style.css`
- 数据请求带缓存版本号（`?v=1`）；页面标题等引用同样带版本号
- 严格读取《04-前后端共享数据合同.md》字段

## 3. 页面结构（顶部导航：今日关注 / 自选股 / 排行榜 / 单股查询 / 个股研究）

### 3.1 今日关注（默认首页）
- 顶部：市场温度条（温度 + 仓位参考）
- 「📋 周一重点关注」：AI 摘要区，显示"基于 {分析日}（周X）收盘分析 · 推荐 {推荐日}（周X）关注"；重点标的卡片带理由/风险，点击跳详情
- 「💰 今日可以关注」：策略信号 + 支撑位买点判断（在关注区间/接近支撑/跌破支撑）
- 无数据时优雅隐藏，不报错

### 3.2 自选股
- 顶部筛选标签：全部 / A股 / 港股 / 美股 / 韩股 / 基金
- 列表按行业分组（category），组标题显示行业 + 数量；卡片显示市场徽章与涨跌
- 过期（stale）标的显示过期样式

### 3.3 排行榜
- 风险收益榜（risk_adjusted_score 降序）、收益预估榜、低风险榜；支持搜索/行业筛选
- 每行展示风险等级、3/5日上涨概率、预期收益、趋势、行业相对强度与理由

### 3.4 单股查询 / 个股研究
- 单股查询支持 A股/港股/美股/韩股/ETF 对比
- 个股研究：K线 + 均线 + 技术指标 + 相似走势 + 基本面 + AI 深度研报 + 免责声明

## 4. 安全与健壮性

- 所有外部 API 请求带超时（fetchWithTimeout）
- 所有用户/外部内容经 escapeHtml 转义（防注入）
- 数据缺失时保持区域隐藏或显示友好空态，不阻塞整页

## 5. 质量要求

- 前端契约由 `tests/test_frontend_*.py` 静态断言保护（区域存在、渲染函数、空数据保护、转义）
