【建议】ADR 与 v2.1 正文不一致 + 两个基于回测证据的架构改进

仓库：serenity-chokepoint-investing-enhanced
作者：吴宇轩（华南师范大学阿伯丁学院 信息管理与信息系统 二年级；u11yw25@abdn.ac.uk）

师叔您好！老师让我认真研读这个框架，我花了两天逐字读完了全部 6 篇 ADR、README 和 SKILL.md，并做了两只标的的封箱回测（立新能源 001258、美光科技 MU），有一些发现想分享给您。

====================================================

A 部分：文档不一致（疑似 v2.0 到 v2.1 迭代遗留）

A1：IR 淘汰阈值 0.5 与 0.3 不一致

- ADR-0001 的硬约束表写的是 IR < 0.5 拒绝
- README / SKILL.md（v2.1）已改为 IR < 0.3 拒绝（0.3~0.5 为弱 alpha、仅小仓位）

建议：在 ADR-0001 增加一段"v2.1 更新说明"，指向现行 0.3 阈值，避免后来者被两个数字误导。

A2：仓位调整公式：乘法与加权不一致

- ADR-0006 用的是乘法公式：最终仓位 = 基础仓位 x (1+调整1) x (1+调整2) x ...
- v2.1 正文已改为绝对百分点加减，并设硬地板 max(基础仓位 x 25%, 0.5%)

建议：在 ADR-0006 补充 v2.1 更新说明，注明乘法公式保留作历史参考。

====================================================

B 部分：两个基于回测证据的架构改进建议

B1：赌注类型应数据化分类，而非仅靠 LLM 判断

ADR-0006 要求 agent 将标的分为 Super Beta / Catalyst Alpha / Event-Driven，但分类依据是 LLM 定性判断。我用同一套信号系统做了对比回测：

标的1：立新能源 001258（高波动"妖股"）
  买入持有：+85.3% | 信号择时：+163.0%（择时大幅胜出）

标的2：美光科技 MU（强趋势牛股）
  买入持有：+423.3% | 信号择时：+161.0%（择时大幅跑输）

同一套策略，在两只标的上结果完全相反。这说明最优持仓周期与仓位逻辑取决于标的的统计特征（波动率、动量半衰期、收益自相关）。

建议：增加一个轻量统计分类器（如 20 日波动率 + 动量半衰期 + ATR），用数据判定赌注类型，与 LLM 定性判断互为校验。

B2：缺少"趋势环境过滤层"（实测最大的盲区）

美光科技回测中，集成投票的 1 日方向命中率按市场环境分段：

  上升段：53.7%
  下降段：45.2%（低于随机！）
  震荡段：56.8%

系统在下跌段系统性误判为看涨。

建议：增加一道"趋势门"：当标的 20/60 日趋势向下时，抑制或降权看多信号。这是我实测中影响最大的一个改进点。
