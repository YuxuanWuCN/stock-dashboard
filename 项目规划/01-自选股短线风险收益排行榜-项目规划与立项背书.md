# 家庭股票自动看板（stock-dashboard）项目规划与立项背书

## 文档状态：v1.0（2026-08-10 全面更新，反映当前实际架构）

> 目标用户：正在学习金融/商科、希望理解量化分析逻辑的学生
> 使用边界：仅作研究和学习；不连接证券账户、不自动下单、不构成投资建议

## 1. 项目是什么

一套"收盘后自动做功课"的家庭量化研究看板：
- 自选 **202 只全球股票**（A股 91 / 港股 36 / 美股 44 / 韩股 10 / ETF基金 21）
- 每天 18:00 自动抓取数据 → 计算指标 → 生成风险收益排行榜 → AI 研报 → 明日关注
- 网页静态托管在 GitHub Pages，前端不计算核心指标、不调用大模型

## 2. 核心能力

| 能力 | 说明 |
|---|---|
| 行情看板 | K线、成交量、均线、单股查询、个股研究 |
| 风险收益排行榜 | 技术面/风险/行业评分 + KNN 历史相似走势预测（3日/5日） |
| AI 研报 | DeepSeek V4 Flash + FinGPT 风格管线（新闻情感 + RAG + 深度报告） |
| 明日关注 | 每日 AI 摘要：基于上一交易日分析，推荐下一交易日关注 |
| 策略信号 | 启明星 / 金叉 / 涨停回调（移植自 KHunter） |
| 模拟盘对决 | 稳健 vs 激进组合每日自动对比 + 预测校准数据（后训练素材） |
| 自选股分区 | 按行业分组 + 市场筛选（A股/港股/美股/韩股/基金） |

## 3. 架构

- 后端：本地 Python 管道（`src/`），Windows 计划任务每日 18:00 运行 `tools/daily_local.ps1`（另设每日 08:00 美股补数据任务 `tools/daily_morning.ps1`，美股收盘后自动对齐美股数据）
- 前端：纯静态 HTML/CSS/JS（`docs/`），无框架，GitHub Pages 托管
- 数据源：A股=新浪主源/东财备用；ETF=腾讯；美股=腾讯 .OQ/.N；港股=腾讯 hk 前缀；韩股=Naver；全部直连模式（避免代理不稳定）
- 版本：网页缓存版本号 v1

## 4. 关键规则

- **不伪造数据**：数据源缺失时明确标记"数据过期"（stale），不编造、不推荐过期标的
- **不承诺收益**：所有预测均为历史统计概率，页面统一标注"研究参考，不构成投资建议"
- **质量门禁**：任何代码改动必须走 `tools/run_quality.ps1`（begin-unit → small → medium → heavy）
- **反馈闭环**：模拟盘对决与市场反馈持续积累，按《05-FinGPT后训练计划》周期性校准参数

| 版本 | 内容 | 状态 |

## 6. 风险与边界

- 数据源依赖第三方公开接口，个别标的可能缺失（如恒生银行数据停在 2026-01），系统会自动标"过期"
- 历史统计 ≠ 未来收益，单日/短期表现不能证明模型优劣，需长期验证
