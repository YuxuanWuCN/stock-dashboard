# 策略进化协议 v1

- 生效日期：2026-08-13
- 适用范围：主策略参数评审、衍生策略冠军评选、模拟盘组合调仓参数

## 1. 主策略评审

- **频率**：每月首个交易日评审一次。
- **依据**：过去 20 个交易日，日超额收益（策略组合 vs 随机对照组 100 次抽样）的均值与 t 检验。
- **判定**：
  - p < 0.05 且超额均值 > 0 → **维持**。
  - 否则 → **判假**，记录到 bug合集/策略记录，**不调参，直接换新假设**。
- 新假设从零开始，重新测满 20 个交易日。

## 2. 衍生策略（周冠军路线）

- 每周日生成 3 个变体进入测试池。
- **测试期 ≥ 20 个交易日**，未满 20 天不参与冠军评选。
- 月度评审与主策略同期，显著性门槛 p < 0.05 / 策略数（多重比较校正）。
- 冠军评选说明：9 个策略同场竞技时，出 1 个 4 周冠军约 35% 概率纯靠运气，报告中必须标注。

## 3. 参数冻结

- 测试期间任何策略参数（阈值/持仓数/权重/KNN-K 等）**一律不动**。
- 调参 = 新假设 → 必须从 20 个交易日的全新测试开始，测试中禁止看结果调参（后视镜偏差）。

## 4. 对照组

| 对照组 | 状态 | 说明 |
|---|---|---|
| 全池等权基准 | ✅ 已有 | 202 只自选股等权（注意：含自选偏差，非市场基准） |
| 随机抽样 100 次 | 🚧 待建 | 随机抽 N 只等权，检验 top-N 是否显著跑赢随机分布 |
| 沪深300 等权 | 🚧 待建 | 市场级基准，检验选股池本身是否跑赢大盘 |

## 5. 诚实条款

- 任何"策略变好"的结论必须附 p 值、样本量、对照方式。
- 禁止写"感觉变好了"。
- 预测准确率等过程指标 ≠ 超额收益等结果指标，报告中不得混用。

## 6. 已知局限

- 当前模拟盘样本仅 4 个交易日（2026-08-07 起），任何统计结论置信度极低。
- 本协议的统计效力随样本积累逐步提升，预计 20 个交易日后（2026-09 中）才有第一轮可判定的评审。
