# PPT修改操作指南 - 针对老师反馈

**目标**：在现有PPT中补充2-3页Slide，解决"买卖逻辑不清晰"和"测试不充分"的问题

**源文件**：`2026中国国际大学生创新大赛_网评路演PPT_Rainbow-FinGPT.pptx`（4.3 MB）

**参考材料**：`PPT素材\PPT补充材料_交易决策与测试方法论.md`

---

## 操作步骤

### Step 1: 备份原文件（5秒）
```
复制文件：
2026中国国际大学生创新大赛_网评路演PPT_Rainbow-FinGPT.pptx
→ 改名为：
2026中国国际大学生创新大赛_网评路演PPT_Rainbow-FinGPT_原始版.pptx
```

### Step 2: 打开PPT，确定插入位置（30秒）
1. 打开原PPT文件
2. 找到当前的Slide结构（目测应该有12-16页）
3. **推荐插入位置**：
   - 如果有"核心技术架构"或"解耦三引擎"的Slide → 在其后插入
   - 如果有"实测结果"或"三板块回测"的Slide → 在其前插入
   - 保险做法：在倒数第2页（总结页之前）插入

### Step 3: 新增Slide 1 - 交易决策流程图（必加，10分钟）

**插入方式**：
- 右键点击左侧Slide缩略图 → 新建Slide → 选择"标题+内容"布局

**标题**：
```
Rainbow-FinGPT 日频交易决策五步流程
```

**副标题**（小字）：
```
每日收盘后（T日 15:00）自动执行，T+1日开盘撮合
```

**正文内容**（使用SmartArt流程图）：
1. 点击"插入" → "SmartArt" → 选择"流程" → "垂直流程图"
2. 输入5个步骤：

```
【步骤1】宏观趋势门控
检查大盘状态（MA20 vs MA60, MACD）
→ 牛市/震荡：继续
→ 熊市：降至30%仓位
→ C浪下跌：全部清仓 🔴

↓

【步骤2】个股Alpha评分
Fama-MacBeth两阶段回归
剥离四因子暴露 → 特质Alpha
门槛：p<0.05 且 IR≥0.30
案例：立新能源涨82%但p=0.35被拒绝

↓

【步骤3】个股趋势过滤
三重验证（全部满足才通过）：
✓ 价格 > MA20
✓ EMA5 > EMA20
✓ 非C浪下跌

↓

【步骤4】权重分配
按Alpha排序，选Top 2-3只龙头
设置8%调仓死区（降低摩擦）

↓

【步骤5】T+1日开盘撮合
买入：开盘价×(1+0.125%)
卖出：开盘价×(1-0.175%)
```

**配色**：
- 步骤1-5的方框用不同颜色（蓝→紫→橙→绿→灰）
- 关键拦截点用红色标注（"C浪下跌"、"立新能源被拒"）

**底部文字框**（黄色醒目框）：
```
💡 关键决策点：
• 强制清仓：大盘C浪下跌（如2026.03存储暴跌，成功规避-15%）
• 拒绝买入：Alpha不显著（如立新能源案例）
• 止损卖出：个股破趋势
```

### Step 4: 新增Slide 2 - 样本内外测试分离（必加，10分钟）

**插入方式**：新建Slide → "标题+双栏内容"布局

**标题**：
```
样本外测试：物理隔绝 + 时序封箱协议
```

**副标题**：
```
严格分离训练期与测试期，杜绝前视偏差
```

**左栏**：时间轴图

用PowerPoint的"插入" → "形状" → "直线"和"文本框"绘制：

```
训练期              测试期
（参数冻结）    （从未见过的数据）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📊 存储板块
├─ 2023年（训练）
└─ 2025Q2-2026Q7（测试）
   Sharpe 4.63, MaxDD 6.5%

📊 黄金板块
├─ 2023年（训练）
└─ 2024年（测试）
   Sharpe 2.87, MaxDD 8.47%

📊 绿电板块
├─ 2023-2024年（训练）
└─ 2025Q3-2026Q3（测试）
   Sharpe 1.19, MaxDD 24.9%
```

**右栏**：防泄漏机制（用图标+文字）

插入3个盾牌图标（"插入" → "图标" → 搜索"shield"），每个配文字：

```
🛡️ 物理数据隔离
✓ 测试期数据存放独立目录
✓ 代码禁止读取测试期外数据
✓ 文件夹权限锁定（只读）

🛡️ 时序封箱撮合（T+1）
✓ T日15:00收盘后计算决策
✓ 仅使用T日及之前历史数据
✓ T+1日09:30开盘价撮合

🛡️ 参数完全冻结
✓ Alpha门槛：p<0.05, IR≥0.30
✓ NALE系数：α=0.4（论文默认）
✓ 趋势门控：MA20（行业标准）
✓ 测试期禁止修改任何参数
```

**底部文字框**（蓝色底色）：
```
⚠️ 与学术标准对标：
Harvey et al. (2016) |t|>3.0因子修剪 • Fama-MacBeth (1973) 两阶段回归 • Newey-West (1987) HAC修正
本项目严格遵循学术规范，非暴力调参
```

### Step 5: 新增Slide 3 - 敏感性分析（可选，8分钟）

**插入方式**：新建Slide → "标题+表格"布局

**标题**：
```
关键参数敏感性测试：证明基准配置非过拟合
```

**副标题**：
```
存储板块样本外测试期（2025Q2-2026Q7）
```

**表格**：插入5行6列表格

| 参数名称 | 基准值 | 测试范围 | Sharpe变化 | MaxDD变化 | 结论 |
|---------|-------|---------|-----------|----------|------|
| Alpha门槛(IR) | **0.30** | 0.20/0.30/0.50 | 4.32/**4.63**/4.51 | 7.2%/**6.5%**/6.8% | 0.30最优 |
| NALE系数(α) | **0.4** | 0.2/0.4/0.6 | 4.21/**4.63**/4.38 | 6.9%/**6.5%**/7.5% | 论文默认最优 |
| MA周期 | **20日** | 10/20/60日 | 3.87/**4.63**/4.02 | 8.1%/**6.5%**/9.3% | 行业标准最优 |
| 调仓死区 | **8%** | 5%/8%/15% | 4.48/**4.63**/4.55 | 6.8%/**6.5%**/7.1% | 8%平衡最优 |
| 领头羊Top N | **2-3只** | Top1/2-3/5 | 4.12/**4.63**/4.29 | 9.2%/**6.5%**/8.7% | 聚焦龙头最优 |

**表格格式**：
- 基准值列用粗体+黄色底色
- Sharpe/MaxDD的基准值用粗体

**表格下方文字框**（绿色底色）：
```
✅ 鲁棒性验证：
• 基准参数在所有测试中表现最优
• 参数在±20%扰动下，Sharpe仍保持4.2+
• NALE α=0.4来自原论文，非本项目调优

⚠️ 为什么不用"最优参数"？
如果用网格搜索找到MA=17时Sharpe=4.71，这是过拟合
我们坚持用学术标准参数，保证可复制性
```

### Step 6: 调整现有Slide顺序（2分钟）

建议的最终Slide顺序：
```
1-3页：封面、目录、背景（保持不变）
4-6页：痛点、解决方案、三引擎架构（保持不变）
【新增】第7页：交易决策流程图 ← 新增
【新增】第8页：样本内外测试分离 ← 新增
9-11页：实测结果、三板块对比（保持不变）
【可选新增】第12页：敏感性分析 ← 可选
12-16页：团队、商业价值、总结（保持不变）
```

---

### Step 7: 统一格式（5分钟）

确保新增Slide与原PPT风格一致：
1. **配色**：使用原PPT的深海夜空蓝主色调
2. **字体**：标题用微软雅黑 Bold 32pt，正文24pt
3. **图标**：使用原PPT同系列的图标风格
4. **页脚**：复制原PPT的页脚格式（页码、项目名称）

---

### Step 8: 保存与检查（2分钟）

1. 另存为：保持原文件名（覆盖）
2. 检查清单：
   - ✅ 新增Slide的文字没有超出边界
   - ✅ 流程图箭头连接正确
   - ✅ 表格数据没有错位
   - ✅ 页码连续
   - ✅ 全屏播放一遍，确认动画效果

## 快捷方式（如果赶时间）

### 最小改动方案（15分钟）
只加1页：**交易决策流程图**

这一页解决了老师最核心的问题"什么时候买入、什么时候卖出"。

在流程图底部用大字号醒目标注：
```
📌 样本外测试说明：
三板块测试期（存储15个月、黄金12个月、绿电12个月）均为训练期后的独立数据
物理隔绝目录 + T+1撮合 + 参数冻结，杜绝前视偏差
详见研报附件第X页
```

这样即使不单独加测试Slide，也在流程图中简要说明了。
