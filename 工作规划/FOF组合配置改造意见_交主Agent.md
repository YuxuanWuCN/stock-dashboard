# FOF 组合配置改造意见（交主 Agent 执行）

> 目的：在不改变 NALE/T-NALE 核心研究价值的前提下，将项目从“情绪/热点驱动的个股或板块择时”扩展为“风险约束下的 FOF 主动配置”。
>
> 本文是改造建议与交接规范，不是已经验证的收益或回撤结论。所有 10% 左右的回撤目标必须通过真实数据、样本外回测和压力测试验证后才能对外表述。

## 1. 先确定新的项目定位

建议对外统一表述为：

> 本项目研究 NALE/T-NALE 对产业链信息、情绪和时效性的刻画能力，并将其作为 FOF 组合中的主动配置信号；在基金/ETF 分散配置、权重上限、风险预算和再平衡机制约束下，检验该信号能否改善组合的风险调整收益。

不要表述为：

- NALE 直接预测养老基金收益；
- NALE 能保证最大回撤不超过 10%；
- 情绪越高就机械地买入热点股；
- 个股回测结果可以直接代表养老 FOF 结果。

核心研究对象从“单只股票是否上涨”改为：

1. 情绪与产业链时效信号能否在行业/基金层面产生可重复的排序能力；
2. 信号如何影响 FOF 的卫星仓位；
3. 风险约束是否能把组合回撤控制在预设风险预算内；
4. 加入 NALE 后，组合的 Sharpe、Calmar、最大回撤、换手率是否优于基准。

## 2. NALE/T-NALE 哪些内容保留

### 2.1 保留原有核心公式

现有 NALE 网络传播仍然是信号层基础：

\[
S_{NALE,t}=(1-\alpha_t)S_{0,t}+\alpha_t W_tS_{0,t}
\]

其中：

- `S_0,t`：截至决策时点可观测的原生事实/情绪得分；
- `W_t`：截至决策时点可获得的产业链或行业邻接矩阵；
- `alpha_t`：传播权重，默认经典值可继续使用 0.4，但应作为冻结基准而不是未经验证的最优参数；
- `S_NALE,t`：资产、行业或基金候选标的的主动配置信号。

现有 `calculate_nale_score()` 和 `calculate_temporal_nale_score()` 的数学含义可以保留，不要为了改成 FOF 而重写传播公式。

### 2.2 保留时效性，但改变解释

T-NALE 的信息半衰期、物理库存时滞、节点年龄和动态 Alpha 仍然有用。它们回答的是：

> 某个信息或产业链冲击在当前时点还有多强的配置价值？

而不是直接回答：

> 明天哪只股票一定上涨？

建议保留：

- 节点信息年龄 `node_ages_days`；
- 信息半衰期衰减；
- `horizon_days`；
- `use_dynamic_alpha`；
- 点时（as-of）输入和历史版本选择；
- 无未来函数的时间序列回测。

### 2.3 保留原有趋势门禁，但提升为组合风险门

Trend Gate 不再只服务于单票清仓，而应作为组合层的风险状态输入：

- 正常状态：允许 NALE 卫星仓按信号配置；
- 风险状态：降低卫星仓上限，增加债券/货币基金/现金；
- C 浪或组合风险门触发：停止新增风险仓，并按预定规则降仓；
- 恢复条件满足后再逐步恢复，而不是单日满仓切换。

注意：卖出发生在跌停或流动性受限时不一定成交，回测必须显式建模成交限制，不能写成“完全规避跌停”。

## 3. 必须新增的组合层

现有 NALE 是信号层，不能直接当成 FOF 优化器。建议新增独立模块，避免把组合逻辑塞入 `scoringv3.py`。

### 3.1 建议模块边界

```text
src/
├── analysis/scoringv3.py              # 现有 NALE/T-NALE 信号层，尽量向后兼容
├── portfolio/
│   ├── __init__.py
│   ├── contracts.py                   # 资产、基金、信号、权重、风险结果契约
│   ├── signal_adapter.py              # 股票/行业 NALE 聚合到基金/ETF层
│   ├── allocator.py                   # 基准权重 + NALE主动偏离
│   ├── risk_budget.py                 # 波动、回撤、集中度和风险状态约束
│   ├── rebalancer.py                  # 调仓、死区、频率和交易成本
│   └── backtest.py                    # 点时组合回测与基准对比
└── sector_rotation/
    └── sector_sentiment_aggregator.py # 复用现有板块情绪聚合能力
```

第一阶段只需实现 `contracts.py`、`signal_adapter.py`、`allocator.py` 和 `risk_budget.py`，不要同时扩展 UI、LLM 或新的预测模型。

### 3.2 从股票信号聚合到基金/行业信号

若 NALE 原始信号来自股票，必须显式聚合到行业或 ETF/基金标的：

\[
S_{j,t}^{fund}=
\frac{\sum_{i\in j} AUMWeight_{i,j,t}\,q_{i,t}\,S_{i,t}}
{\sum_{i\in j} AUMWeight_{i,j,t}\,q_{i,t}}
\]

其中：

- `j` 是行业、ETF 或基金候选；
- `S_i,t` 是个股 NALE/T-NALE 信号；
- `q_i,t` 是数据质量/置信度权重；
- `AUMWeight` 可以来自基金持仓或行业权重，但必须是决策时点已知数据；
- 分母为 0 时必须返回缺失并记录原因，不能静默填随机数或默认强信号。

聚合方式要做敏感性对照：等权、流通市值权重、置信度权重。不要把其中一种方式直接称为“最优”。

## 4. 建议的配置公式

### 4.1 基准 + 卫星偏离

组合权重不要由情绪信号从 0 直接跳到满仓，建议：

\[
\tilde w_{j,t}=w^{base}_{j,t}+\lambda_t\,g(S^{fund}_{j,t})
\]

其中：

- `w_base` 是战略基准配置；
- `g()` 是截面标准化/排名函数，避免原始分数尺度漂移；
- `lambda_t` 是风险状态下的主动风险预算；
- `tilde w` 经过风险约束后才是最终权重。

最小可行版本可使用：

```text
战略底仓：债券/货币基金 + 宽基或低波动资产
卫星仓：NALE/T-NALE 排名靠前的行业 ETF/基金
防御仓：由风险状态机决定的债券、货币基金或现金
```

卫星仓比例不要预设为固定 10% 或 30% 作为结论，应在训练期冻结规则，在样本外比较多个预先声明的候选风险预算。

### 4.2 必须满足的权重约束

\[
\sum_j w_{j,t}=1
\]

\[
0\leq w_{j,t}\leq w_{j}^{max}
\]

\[
\sum_{j\in satellite}w_{j,t}\leq B_{satellite,t}
\]

另外建议增加：

- 单一基金/ETF上限；
- 单一行业上限；
- 最低防御资产比例；
- 换手率上限；
- 现金或货币基金流动性约束；
- 无有效信号时回到基准，而不是强行选股。

### 4.3 风险缩放

可采用组合波动率目标作为第一版风险缩放：

\[
w^{risk}_{t}=w_t\cdot
\min\left(1,\frac{\sigma^*}{\hat\sigma_{p,t}+\epsilon}\right)
\]

其中 `sigma*` 是预先声明的年化波动目标，`hat_sigma` 只使用历史收益估计。剩余权重分配到防御资产。

最大回撤不是一个可以在每日调仓时直接无偏预测的变量，因此“MaxDD ≤ 10%”应作为评价目标和触发式风险管理规则，而不是未经验证的硬保证。可以设计分层响应：

```text
回撤 < 5%：正常风险预算
5% <= 回撤 < 8%：降低卫星仓上限
8% <= 回撤 < 10%：进一步降风险、提高防御仓
回撤 >= 10%：进入保护状态，停止新增风险仓，按规则再平衡
```

阈值只是待验证的候选配置，不能在没有回测的情况下宣称有效。

## 5. 时间尺度要分层，不要让养老目标吞掉 NALE

这是本次改造的关键：

- 养老/FOF 战略配置：月度或季度评估；
- NALE/T-NALE 主动信号：周度或日度计算；
- 实际调仓：设置死区和最小调仓幅度，避免新闻情绪造成过度换手；
- 极端风险门：可以日度触发，但应有恢复确认。

因此，NALE 的高时效性并没有失效，而是被放到“卫星仓择时与行业轮动”这一更合适的时间尺度。底仓不应因一个短期情绪脉冲全部切换。

## 6. 实验设计：必须新增的四组对照

至少做以下组合，而非只展示 NALE 组合本身：

1. `Baseline-FOF`：战略基准权重，定期再平衡，不使用 NALE；
2. `NALE-FOF`：使用 NALE/T-NALE 主动偏离，但暂不启用组合风险缩放；
3. `Risk-Constrained NALE-FOF`：启用集中度、波动率、换手和风险状态约束；
4. `Sentiment-only`：只使用情绪信号，用于验证 NALE 网络和时效模块的边际贡献。

建议做消融：

- 静态 NALE vs T-NALE；
- 固定 Alpha vs 动态 Alpha；
- 不同信息半衰期；
- 不同基金/行业聚合方式；
- 不同卫星仓预算；
- 有无 Trend Gate 风险门。

每组都要报告：

- 年化收益、年化波动、Sharpe、Sortino、Calmar；
- 最大回撤及回撤持续时间；
- 月度胜率和亏损月份；
- 换手率、交易成本、滑点假设；
- 防御资产占比和空仓/拒绝信号比例；
- 不同市场状态的分段结果；
- 训练期、验证期、样本外期的结果；
- 失败案例和信号缺失情况。

## 7. 数据和研究纪律（必须遵守）

1. 组合候选必须使用真实、可溯源的基金/ETF收益和持仓数据；不能用股票回测结果冒充基金表现。
2. 基金持仓和行业权重必须按点时数据处理，禁止使用事后披露的未来持仓。
3. 不覆盖旧产物；新增结果统一写入独立目录，例如 `reports/fof_rebuild_20261013/`。
4. 先完成数据清单、来源和有效区间，再开始组合回测。
5. 缺失数据直接记录为缺失或停止该实验；禁止静默合成数据。
6. 交易成本、申赎费、管理费、滑点、调仓频率和最低交易单位必须写入实验配置。
7. 10% 最大回撤只能作为目标/约束候选，不能作为预设结果。若真实数据无法达到，应诚实报告并调整研究问题。
8. 任何对外数字都附数据路径、区间、标的数、代码版本和复算命令。

## 8. 给主 Agent 的执行顺序

### P0：文档与数据契约

- 阅读 `AGENTS.md` 和 `bug合集`；
- 按项目质量门禁要求开始任务；
- 建立 `portfolio/contracts.py` 的输入输出契约；
- 盘点真实基金/ETF候选数据、覆盖区间、费用和点时字段；
- 不修改现有 NALE 公式。

### P1：信号适配

- 实现股票/行业 NALE 到基金/ETF层的聚合；
- 对缺失、无成分、分母为 0、节点年龄非法等情况 fail-closed；
- 为静态 NALE、T-NALE、动态 Alpha 保留统一接口；
- 用手算小样本验证 `S_NALE=(1-alpha)S0+alpha*WS0`。

### P2：组合配置和风险层

- 实现基准权重 + 主动偏离；
- 加入权重、集中度、卫星仓、波动率和换手约束；
- 加入回撤状态机，但将 5%、8%、10%作为可配置候选阈值；
- 组合风险层不得修改原始 NALE 信号，便于做消融实验。

### P3：点时回测

- 实现 Baseline、NALE、Risk-Constrained NALE、Sentiment-only 四组；
- 显式处理调仓时点、T+1、交易成本、滑点和不可成交；
- 产出逐日权重、信号、风险状态、交易和净值日志；
- 所有结果写入新目录，不覆盖既有报告。

### P4：验证和独立复核

- 运行正常、边界、缺失、失败路径测试；
- 做截断不变性测试：未来数据变化不能改变过去权重；
- 用独立脚本复算净值、最大回撤和组合权重和；
- 按 small → medium → heavy 顺序执行项目测试；
- 只有真实数据回测完成后，才能决定论文和项目材料是否改口径。

## 10. 最重要的研究判断

本次不是把 NALE 改成低频、无关痛痒的养老模型，而是把它从“直接下单的个股信号”提升为“FOF 组合中的主动风险预算信号”：

```text
原来：NALE/T-NALE -> 个股/热点交易
现在：NALE/T-NALE -> 行业/基金信号 -> 卫星仓配置
                         + 基准底仓
                         + 风险预算
                         + 回撤门控
                         -> FOF组合
```

因此，NALE 的时效性、产业链传导和情绪信息仍然是项目的研究核心；新增的只是把信号转换成可审计、可约束、可回测的组合权重。
