## 🎯 本周核心任务：PC5向量升级与A股时效性增强

### 方案：将PC5升级为"五维时效复合向量 (PC5-Temporal)"

基于现有T-NALE框架，构建一个融合以下5个维度的复合向量：

#### **P1: 基本面稳健性 (Fundamental Stability)**
- 财务质量评分
- 行业地位指标
- 增长可持续性

#### **P2: 市场情绪传导 (Sentiment Propagation)** 
- LLM新闻情绪嵌入
- 社交媒体热度
- 机构关注度变化

#### **P3: 技术动量时效 (Technical Momentum Decay)**
- 价格动量 + 半衰期衰减
- 成交量放大系数
- 波动率聚类

#### **P4: 板块共振强度 (Sector Resonance)**
- T-NALE板块协同广度
- 涨停龙头溢出效应
- 产业链时滞传导

#### **P5: 宏观周期因子 (Macro Cycle Alignment)**
- 市场状态机状态
- 政策敏感度
- 流动性环境

### A股时效性增强机制
1. **滚动窗口校准** (30天历史窗口)
2. **双波峰时效性动态alpha** (已实现)
3. **拒绝预测机制** (低置信度主动放弃)
4. **分段稳定性验证** (前半段/后半段对比)

## 🚨 风险控制与诚实原则

### 协作规则（来自AGENTS.md）
1. **不伪造数据或性能结果** - 如果回测效果不佳，诚实记录
2. **独立复核** - 不能把测试通过当作正确性证明

4. **数据版本控制** - 只有质的提升才能覆盖前版本

### 预设失败场景应对
- **场景1**: PC5命中率仍低于55% → 保留原T-NALE，记录尝试
- **场景2**: 回测过拟合严重 → 增加正则化，减少参数自由度
- **场景3**: 计算性能不可接受 → 引入缓存与向量化优化
