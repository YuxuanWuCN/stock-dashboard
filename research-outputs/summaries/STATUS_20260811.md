## 🔧 技术细节

### 编码问题根源
- Windows PowerShell 默认 GBK 编码
- Python `sys.stdout.encoding` 为 `gbk`
- JSON 写入时中文变成 `???`

### 解决方案
```powershell
# 在所有 PowerShell 脚本开头添加
$env:PYTHONIOENCODING = "utf-8"
$env:PYTHONUTF8 = "1"
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8
chcp 65001 > $null
```
