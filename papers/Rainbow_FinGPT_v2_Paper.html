Abstract

随着自然语言处理（NLP）与大语言模型（LLM）技术的飞速发展，将非结构化金融文本信息（如新闻资讯、研报、市场情绪）与经典多因子资产定价理论（如 Fama-MacBeth 截面回归模型）深度融合，已成为现代量化投资的前沿方向。本文系统阐述了 Rainbow-FinGPT v2 系统的整体架构、核心数学模型、工程实现以及实证回测表现。系统独创性地提出了“双循环自适应演化架构”：外循环通过动态校准与反馈机制追踪宏观与行业风格漂移；内循环依托 FinGPT/DeepSeek 语义解析引擎、Fama-MacBeth 截面风险溢价估计、自适应趋势门（Trend Gate）与波动约束（Constraints System），构建了覆盖 A 股、港股及美股全市场的高置信度标的排序与组合构建流水线。封箱测试与多周期实证检验表明，引入 LLM 语义增强与趋势过滤机制后，组合在信息比率（IR）、最大回撤控制及超额收益（Alpha）捕获能力上均显著优于传统多因子基准。

关键词： Rainbow-FinGPT；大语言模型；多因子模型；Fama-MacBeth 回归；量化投资；情绪分析；趋势过滤

引言与研究背景

现代金融市场具有高度的非线性、非平稳性以及信息不对称特征。传统的量化多因子模型（如 Fama-French 三因子、五因子模型）主要依托历史量价数据与低频财务报表，在面临突发舆情、政策脉冲及行业结构性变革时往往存在显著的时滞效应。

与此同时，以 DeepSeek、ChatGPT 为代表的大语言模型在上下文理解、因果推理和情感细粒度挖掘方面展现出前所未有的能力。然而，直接将纯语言模型应用于资产定价面临“幻觉风险”、“缺乏风险溢价数学约束”以及“对偶回测困难”等工程与学术瓶颈。

针对上述挑战，我们设计并实现了 Rainbow-FinGPT v2 系统。本研究的核心贡献包含语义与量化融合框架、Fama-MacBeth 两阶段回归约束、Trend Gate 趋势风控拦截以及基于市场真实反馈的闭环参数校准。

Fama-MacBeth 截面风险溢价估计模型

为了防止因子过拟合，系统在量化评分前执行两阶段 Fama-MacBeth 截面回归： $$\begin{equation} R_{i,t} - R_{f,t} = \alpha_i + \sum_{k=1}^K \beta_{i,k} F_{k,t} + \epsilon_{i,t}, \quad t = 1, \dots, T \end{equation}$$ 在每个时间截面 t，用第一阶段得到的因子载荷 β̂i, k 对超额收益率进行截面回归，求解各因子在当期的风险溢价 γk, t： $$\begin{equation} R_{i,t} - R_{f,t} = \gamma_{0,t} + \sum_{k=1}^K \gamma_{k,t} \hat{\beta}_{i,k} + \eta_{i,t}, \quad i = 1, \dots, N \end{equation}$$ 因子的长期平均溢价及其 t 统计量计算公式为： $$\begin{equation} \bar{\gamma}_k = \frac{1}{T} \sum_{t=1}^T \gamma_{k,t}, \quad t(\bar{\gamma}_k) = \frac{\bar{\gamma}_k}{\hat{\sigma}(\gamma_k) / \sqrt{T}} \end{equation}$$ 只有满足 |t| ≥ 1.96（显著性水平 5%）的因子才被赋予高权重准入机制。

大语言模型语义情感与领先指标度量

针对标的 i 在时间窗口 τ 内的文本资讯集合 𝒟i = {d1, d2, …, dM}，利用 FinGPT 提取多维情感评分与事件重要度权重 wm： $$\begin{equation} S_{i}^{\text{LLM}} = \sum_{m=1}^M w_m \cdot \Phi_{\text{FinGPT}}(d_m) \end{equation}$$ 将 SiLLM 与基本面和动量指标结合，得到综合评分： Scorei = wf ⋅ Z(Fundamentali) + wt ⋅ Z(Technicali) + ws ⋅ Z(SiLLM) + wl ⋅ Z(Leadingi)

Fama-MacBeth 风险溢价回归估计核心实现

以下代码展示了如何对多因子进行两阶段截面回归，并计算 t 显著性统计量以过滤非显著伪 Alpha 因子：

import numpy as np
import pandas as pd
import statsmodels.api as sm

def estimate_fama_macbeth(excess_returns, factor_exposures):
    """
    两阶段 Fama-MacBeth 回归估算因子风险溢价
    excess_returns: pd.DataFrame (T x N), 个股超额收益率时间序列
    factor_exposures: pd.DataFrame (N x K), 因子载荷载矩阵
    """
    T, N = excess_returns.shape
    K = factor_exposures.shape[1]
    
    # 阶段二：对每个时间截面 t，用第一阶段的 factor_exposures (beta) 对收益率做截面回归
    gammas = []
    for t in range(T):
        r_t = excess_returns.iloc[t, :]
        # 截面回归: R_{i,t} = gamma_0 + \sum gamma_k * beta_{i,k}
        X = sm.add_constant(factor_exposures.values)
        model = sm.OLS(r_t.values, X).fit()
        gammas.append(model.params) # 包含截距项和各因子的 risk premium
        
    gammas_df = pd.DataFrame(gammas, columns=['const'] + list(factor_exposures.columns))
    
    # 计算长期风险溢价均值及 t 统计量
    mean_premium = gammas_df.mean()
    std_premium = gammas_df.std()
    t_stats = mean_premium / (std_premium / np.sqrt(T))
    
    results = pd.DataFrame({
        'Risk_Premium_Mean': mean_premium,
        't_Statistic': t_stats
    })
    return results

自适应趋势防御门控（Trend Gate）核心过滤实现

以下代码展示了如何利用个股均线动量、MACD 指标以及自定义波浪形态过滤左侧抄底和主跌段（C浪阶段）标的：

class TrendGate:
    def __init__(self, ma_period=20):
        self.ma_period = ma_period

    def check_gate_status(self, close_prices, macd_hist, wave_phase):
        """
        判断标的趋势防御门控状态
        close_prices: np.ndarray, 历史收盘价序列
        macd_hist: float, 当前周期的 MACD 柱状值
        wave_phase: str, 当前个股处于的波浪形态阶段 (e.g., 'Phase_A', 'Phase_C')
        Returns: bool (True 为准入，False 为拦截过滤)
        """
        if len(close_prices) < self.ma_period:
            return False
            
        current_price = close_prices[-1]
        ma_val = np.mean(close_prices[-self.ma_period:])
        
        # 1. 均线过滤：价格必须运行在 20 日均线之上
        ma_filter = current_price > ma_val
        
        # 2. 动量过滤：MACD 绿柱动量增强，过滤阴跌探底期
        momentum_filter = macd_hist > 0
        
        # 3. 波浪防御：严防 C 浪主跌探底期
        wave_filter = (wave_phase != "Phase_C")
        
        # 门控开关：综合三项防御性过滤器
        is_admissible = ma_filter and momentum_filter and wave_filter
        return bool(is_admissible)
