## 2. 实验一：Trend Gate 逐日事件研究

### 2.1 时点与交易约束

- 信号在 t 日收盘后产生，只用截至 t 日的数据（`mom_20d = close[t]/close[t-20]-1`；`MA60 = mean(close[t-60:t])`，不含当日）
- **t 日收盘价不可成交**（信号此刻才可知），统一 **t+1 日收盘进场**
- 进场日涨停（买不进）或停牌 → 事件剔除出可交易样本；退出目标日跌停或停牌 → 顺延至下一可成交日，最多 5 个交易日
- 事件收益的显著性用**日度截面均值序列**做 Newey-West HAC 校正，缓解重叠窗口与截面相关

### 2.4 诚实结论

1. **在当前样本期与检验设定下，未能支持「下行拦截能规避下跌」的假设**：三种安慰剂设计下，拦截组的单侧「劣于随机」经验 p 值均为
   **1.0000**（同权重读数下亦未能拒绝无差异原假设）。门禁的设计假设（下行趋势标的在未来持有期内将延续深幅下跌）
   在本样本期内未能得到实证支持，交集配对日期上的池化均值差反而呈现样本特定的超跌反弹迹象。
2. **序列相关校正后，主口径下几乎没有显著结论**。20 日窗口彼此重叠使日度贡献序列 ACF(1) 高达
   +0.931，
   按日独立重抽样会把标准误低估：HAC SE = 0.0095
   vs i.i.d. bootstrap SE = 0.0042
   （比值 2.25×）：
   | 检验 | 事件加权差 | i.i.d. p（不可用） | **HAC p（采用）** | block5 p（稳健性） |
   | :--- | ---: | ---: | ---: | ---: |
   | 触发 vs 非触发池（主口径） | +1.10% | 0.0090 | **0.2451** | 0.2088 |
   | 触发 vs 纯对照 | +1.74% | 0.0000 | **0.0314** | 0.0224 |
   | 顺势 vs 纯对照 | +0.92% | 0.0011 | **0.1058** | 0.0865 |
   | 触发 vs 顺势（门禁自身分辨力） | +0.81% | 0.0864 | **0.4425** | 0.4040 |

   即：**门禁核心区分的对比组（触发 vs 顺势）在控制时序依赖后未能拒绝无差异原假设**（HAC p = 0.4425）；触发组相对纯对照组的优势在主口径下
   处于显著边缘（HAC p = 0.0314），
   在自由口径下为 0.0076，
   **结论对样本口径与滞后阶数敏感，不足以支撑稳健的择时发现**。
3. **等权日口径下同样全不显著**：触发组 vs 池的等权日差
   -0.05%
   （HAC t = -0.09，
   p = 0.9265）。
   事件加权与等权日的差异集中在**触发数最多的少数交易日**：触发最密集的 10% 交易日
   （承载 20.0% 的信号）同日差异 +3.90%，
   其余交易日 +0.59%，高触发日贡献加权差异的约 62%。
   **两种口径必须同时陈述。**
4. **同日匹配设计的口径限制**：该设计在 196 个交易日的抽样池事件数少于触发数，
   每次抽样平均覆盖 30,541 条（目标 42,212 条），
   触发最密集的日期上系统性欠采样。按该设计自身的（被截断）日权重，目标组均值为
   +1.20%，与基线 +0.95% 同权重可比，
   而非与全样本均值 +2.68% 相比。
5. **纯对照组（互斥）表现最差**：20 日均值 +0.94%、平均最大回撤 -9.71%，
   低于拦截组 +2.68% 与顺势组 +1.86%。
6. **事件级抽样会低估标准误**（SD 0.0030 vs 0.0004）：
   它把同一天几百只股票的共同涨跌当作独立信息。v1 用的正是这一类设计（且抽样量固定 10,000、池含触发样本），
   其"显著"结论不具备统计效力。
7. **涨跌停约束的实际影响**：进场日涨停拦截 162 次（触发组）、
   停牌 891 次；退出日因跌停顺延的事件占比
   0.2651%（平均顺延 0.0044 个交易日）。
   约束的**实质影响**是把 24,240 条（触发组）
   无法观测涨跌停状态的事件排除在可交易样本之外，从而把受约束口径限制在 199 支标的上。

## 3. 实验二：Fama-MacBeth HAC 截面回归

### 3.1 计量口径

- 被解释变量：**t → t+1 可交易收益**（`ret_next`）
- 有效截面期数 T = **584**，截面标的数 = 199，观测 115,769
- 每期截面最小股票数 30；逐期截面 z-score（ddof=0，会使 λ 水平比 ddof=1 高约 0.25%，不影响 t 值）
- Newey-West Bartlett 核，滞后阶数 **q = 5**（由 T 计算，非人工指定）
- 移动区块 Bootstrap：区块长度 8（T^(1/3)），1000 次
- 多重检验：BH-FDR 与 Bonferroni，检验次数 = **6**（因子数）
- 年化 244 日；rf = 1.50%/年（λ 为总收益溢价，另给出扣 rf 超额口径字段）
- 经济学含义：截面回归因子斜率 λ_t 体现的是截面标准化因子暴露的边际定价价格（exposure price），并非可直接执行的投资组合净收益；严禁将因子溢价年化解读为实际交易策略的复合年化收益率（CAGR）。重叠持有期事件收益亦不构成可执行策略净值或夏普比率。

### 3.4 诚实结论

1. **前视偏差的量级**：把被解释变量从同期收益改成 t+1 收益后，`mom_20d` 的 NW t 从 +14.09 降到 -0.16，
   `price_pos` 从 +33.92 降到 -1.04。
   v1 报告中「短周期动量与价格位置因子具备稳健定价能力」的结论**不成立**。
2. **主口径下仅 `amihud` 通过 5% FDR**（NW t = +3.24，BH q = 0.0073）。
3. **但该显著性不稳健**：剔除涨停观测（重建口径）后 `amihud` 的 NW t 降到 +0.98（不显著）；
   若改用字面口径（`hit_limit==1 且 ret>0`）则 NW t = +2.78，
   **BH q = 0.0326，在该口径下仍然通过 5% FDR**；
   仅用官方复权收益标的时为 +2.32（BH q = 0.1206，不显著）。
   也就是说：两种剔除口径的差别不仅是"定义"，更主要是**覆盖范围**——重建口径剔除 1,001 行，
   字面口径只剔到 450 行，差额来自 `ret` 缺失、方向只能由 close 收益推断的涨停样本。
   **结论随口径在"显著/不显著"之间翻转，因此不足以作为稳健的多因子发现。**
4. 其余因子（`mom_20d` / `mom_60d` / `vol_20d` / `turnover_20d` / `price_pos`）在任何口径下均不显著。
5. 结论应表述为：**在本样本期与当前因子集下，实证检验未能拒绝因子风险溢价为零的原假设**；历史报告中 Harvey |t| ≥ 3 的多因子叙事缺乏证据，且因子斜率属于回归暴露定价而非可直接执行策略收益。

## 4. 局限性与已知缺口

**样本规模实测**：主口径截面规模 195~199 支/期
（均值 198.2，共 584 期）；
「仅官方复权收益」稳健性口径为 95~99 支/期；
截面平均 R² = 0.2021。

- 面板不含 ST 标记，无法识别 ±5% 涨跌幅限制的 ST 标的，其涨停/跌停判定按 10% 处理。
- hit_limit 字段仅覆盖 199 支标的，其余 100 支只能进入无约束口径。
- 面板无开盘价与最高/最低价（A/C 组），进场价只能用收盘价近似，无法建模盘中成交。
- 同一标的连续触发日的持有窗口高度重叠，已用日度截面均值 + NW HAC 与日期级 cluster bootstrap 缓解，但仍非独立同分布样本。
- 「随机日期安慰剂」的分布只覆盖抽样池一侧的抽样方差；目标组自身的方差与两侧协方差由 cluster_bootstrap_diff（日期级 cluster bootstrap 配对差）承担，结论以后者为准。
- 同日匹配安慰剂在触发最密集的交易日上会因池子事件不足而被截断，其基线与被检验统计量存在权重错配，故同时报告 target_mean_under_matched_weights 供同权重比较。
- 面板中具备官方复权日收益 ret 的只有 99 支标的；主口径对其余标的采用 close 的收盘到收盘收益替代，替代误差已在 report.md §1 量化披露，但仍属测量噪声来源。
- ret 字段在约 100 支标的上缺失，属于上游数据交付缺口，本轮按可用真实数据如实报告，不补齐、不插值。
- 被解释变量为个股总收益而非超额收益，λ 中混入市场收益成分；已同时给出扣除 rf 的超额口径字段。
- 因子集合沿用 v1 的 6 个，未做因子正交化，因子间相关性会削弱单个 t 值的解释力。
- 面板不含 ST 标记，无法识别 ±5% 涨跌幅限制标的；剔除涨停的稳健性口径按 |涨幅触限| 判定。
