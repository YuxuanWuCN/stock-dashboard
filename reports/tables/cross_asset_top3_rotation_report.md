# 跨资产“明日预期盈余”轮动实证

## 结论

在 2024-02-27 至 2026-09-24 的 629 个共同交易日样本中，混合榜单的表现优于
股票池和期货池：累计收益为 **24.61%**，年化夏普为 **0.475**，最大回撤为
**-29.14%**。股票 Top 3 的对应数值分别为 -18.49%、-0.061 和 -44.70%。

以股票 Top 3 当月复利收益小于或等于 0 作为“股票行情差的月份”定义，共识别出
17 个弱势月；混合榜在其中 **17/17（100%）** 的月份持有期货，平均期货权重为
**77.92%**。这支持了混合榜会在股票弱势阶段把部分仓位配置到期货的命题。

## 对比指标

| 组合 | 累计收益 | 年化夏普 | 最大回撤 | 夏季最大回撤 |
| --- | ---: | ---: | ---: | ---: |
| 纯股票 Top 3 | -18.49% | -0.061 | -44.70% | -40.48% |
| 纯期货 Top 3 | -2.25% | 0.057 | -29.39% | -29.15% |
| 混合 Top 3 | **24.61%** | **0.475** | **-29.14%** | **-28.91%** |

## 可复现方法

- 股票池：300750、601012、600438；使用腾讯公开接口的前复权日线。
- 期货池：SA、FG（郑商所主连）及 GC=F（COMEX 黄金连续期货）。SA、FG 使用
  `data/raw` 中的郑商所日线；GC=F 使用 Yahoo Finance Chart API 日线并固化至
  `data/raw/yahoo_gc_futures_daily_raw.csv`。
- 每日分数：仅使用该日及此前 20 个交易日的平均收益和波动率；股票仅做多，期货依
  20 日动量决定多空方向。下一交易日收益单独结算，因此不存在用次日收益参与当日排名。
- 每日等权持有各池排名前 3 的候选标的。股票池和期货池均有恰好三个候选，故三组
  比较均为严格的 Top 3 组合。

原始面板和数据来源记录在：

- `data/processed/cross_asset_top3_panel.csv`
- `data/processed/cross_asset_top3_panel_metadata.json`
- `reports/tables/cross_asset_top3_rotation_metrics.json`

## 范围限制

这是一项按题目要求的简单、无交易成本日频实证，不包含手续费、滑点、保证金利息、
换月和股票停牌交易限制。GC=F 为美元计价的 COMEX 合约；本回测比较的是各标的
归一化日收益，尚未加入人民币/美元汇率及跨市场交易时段的执行摩擦。
