# 预测准确率评估框架（reports/prediction_accuracy）

## 这个目录是什么

离线、不联网、可复现的「股票方向预测准确率」评估结果。工具：
`tools/prediction_accuracy_harness.py`，测试：`tests/test_prediction_accuracy_harness.py`。

目标口径（与目标 "80% 股票预测率" 对应）：
- **方向准确率**：交易日 t 预测未来 h ∈ {1,3,5} 日涨跌，与实际方向比对。
- **选择性预测**：只在满足置信度条件时出手，出手准确率 vs 覆盖率。
- **横截面命中率**：信号排名 top 分组的股票未来 h 日上涨比例（排行榜口径）。

## 基线结果（2026-08-14，201 只股票 × 268 交易日，前复权日线）

1. **无条件方向预测：约 50%**（抛硬币）。动量/均线/RSI/量能等 16 个信号、
   1/3/5 日预测期，全部落在 48.5%–52.7%。
2. **选择性预测（置信度过滤）**：3 日最强为 ret1 幅度≥1% 时反向操作
   53.6%（覆盖率 1.1%）；其余 50–52%。**没有配置接近 80%**。
3. **横截面 top10 命中率：48.5%–50.7%**，与随机相当；部分信号 bottom10
   反而更高（短期均值回归特征）。
4. 现有 LLM 情绪 alignment_rate ≈ 34.7%（reports/calibration）——
   **低于抛硬币**，说明当前情绪信号方向映射大概率有系统性问题。

## 结论（诚实基线）

**仅用日线 OHLCV 技术信号，任何口径都到不了 80%。** 这不是调参能解决的；
在 4 万+样本上所有信号都是噪声水平，继续调阈值只会过拟合。

## 通往 80% 的现实路径（按优先级）

1. **修复 LLM 情绪信号**：alignment_rate 34.7% < 50%，暗示信号可能被系统
   性反转（或标签映射错误）。若翻转后 ~65%，再叠加置信度过滤有机会逼近
   更高精度。步骤：先离线重算 sentiment_score → 实际方向的对齐率，定位
   反转点（新闻日期错位？多空映射反了？）。
2. **KNN 相似度方向准确率**：项目旗舰预测器（src/analysis/similarity.py）
   尚无方向准确率离线评估。给 harness 增加 KNN 方向评估。
3. **事件驱动策略胜率**：limit_up_pullback、morning_star 等策略的回测
   胜率（backtest_engine.win_rate）是更接近"交易预测率"的口径，验证其
   在 80% 目标下的表现与样本量。
4. **口径收敛**：把 "80% 预测率" 定义为「高置信度出手子集的方向准确率
   ≥80%，覆盖率最大化」。这是唯一统计上诚实的 80% 口径，需与用户确认。
5. **横截面优化**：用 ranking 打分（scoring.py 的技术+风险+行业+KNN 组合）
   替代单信号，评估 top-N 命中率与排序相关性（Spearman）。

## 假设与局限

- 方向口径：close[t+h] vs close[t]；中性(=0)单列，未计手续费/滑点/涨跌停。
- 数据：项目自有 qfq 日线缓存，仅覆盖自选/扫描股票池（选择与幸存者偏差），
  样本期约 13 个月，结论对时段敏感。
- 特征严格只用 t 及之前数据（测试中有无未来函数的结构断言）。
- 集成为固定规则投票，未做训练；学习型集成留待后续轮次。
- 本目录结果均为离线统计，不代表真实交易成绩。
