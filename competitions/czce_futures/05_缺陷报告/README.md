## 一句话结论

> 模型的期货价格是真的，但**基差与库存/仓单是随机模拟数据**。
> 因此 Trend Gate 门控、TSMOM 期限结构动量、NALE 产业链信号，都在对一个随机数序列做反应。
> **在 B1/B2 修复前，不要基于当前信号交易，也不要把当前回测数字写进论文。**

## 最严重的两项

| 编号 | 缺陷 | 关键证据 |
| :--- | :--- | :--- |
| **B1** | 基差/现货由随机过程模拟，却宣称实测校准 | 真实主力基差均值 −219.42 vs 模拟 −490.24（**2.23 倍**）；16 个抽样点中 **3 个符号相反** |
| **B2** | 库存/仓单同为随机模拟，占 NALE 权重 40% | 仅因库存顺延一日，NALE 从 **−0.7056 跳到 −0.1179** |

## 最容易在答辩被问倒的一项

**B3**：`trend_gate` 权重在两条分支里不一致（价格项权重 0.45 ↔ 0.65），
导致**同一份数据、同一天**，接不接 TSMOM 会给出**相反**的信号：

| 口径 | Z | 状态 | 动作 |
| :--- | ---: | :---: | :--- |
| 带 TSMOM | 0.343 | 0 | 观望 |
| 不带 TSMOM | 0.650 | 1 | 做空 95% |
