## 技术提示

### 如何制作流程图（任务2 Slide 1）
**方法1（推荐）**：使用SmartArt
1. 插入 → SmartArt → 流程 → 选择"垂直流程图"或"基本流程图"
2. 输入5个步骤的文字
3. 设计 → 更改颜色 → 选择"多彩"
4. 调整每个方框的填充颜色（蓝→紫→橙→绿→灰）

**方法2（备用）**：使用形状+文本框
1. 插入 → 形状 → 选择"圆角矩形"
2. 复制5个，垂直排列
3. 插入 → 形状 → 箭头，连接各步骤
4. 在每个矩形内输入文字

### 如何插入图标（任务3 Slide 2）
1. 插入 → 图标 → 搜索"shield"（盾牌）
2. 选择3个盾牌图标，插入到右栏
3. 调整大小（约3cm × 3cm）
4. 在每个图标旁边插入文本框，输入对应文字

### 如何制作表格（任务4 Slide 3）
1. 插入 → 表格 → 6列×6行
2. 输入数据（复制粘贴任务4中的表格内容）
3. 设计 → 表格样式 → 选择简洁风格
4. 右键 → 单元格格式 → 设置基准值列为黄色底色
5. 选中基准值数据 → 加粗

## 常见问题处理

**Q1：找不到原PPT中合适的插入位置？**
A：保险做法 - 在倒数第2页（总结页之前）插入，不会破坏现有逻辑。

**Q2：SmartArt流程图太难用？**
A：用普通文本框+箭头也可以，效果相同。

**Q3：表格数据对不齐？**
A：先在Excel里做好表格，然后复制粘贴到PPT。

**Q4：配色不知道怎么选？**
A：用取色器工具（格式 → 形状填充 → 取色器）从原PPT中吸取颜色。

**Q5：时间不够怎么办？**
