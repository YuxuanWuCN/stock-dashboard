## 1. 业务背景与问题定义 (Context & Problem Statement)

在 2026 中国国际大学生创新大赛（大创赛）及养老金融实际落地场景中，投研产品面临两极割裂的痛点：
1. **痛点 A（过于复杂则难以下沉大众）**：现有的机构量化投研看板（`index.html`）功能极度硬核，充满 Fama-MacBeth 回归、Soft-Spearman Rank IC、CSMAR 因子库和复杂 K 线，对长辈投资者及大众评委认知负担沉重，极易产生金融焦虑；
2. **痛点 B（过于通俗则缺乏学术护城河）**：组员交付的最新前端（`rainbow-fingpt-web`）在适老化视觉、防焦虑摄影横幅、SVG 环图与温度仪表盘上极具亲和力与产品美感，但底层的“机构量化研报模式”仅展示了策略收益对比与相关性矩阵，**遗失了用户原系统中最核心的“业内级学术硬核因子与计量经济学实证底座”**（如两阶段 OLS 回归显著性、国泰安 CSMAR 字段映射、NALE 动态图谱因果推断与 BibTeX 规范引用）。

**解决方略**：
执行“双核融合”架构——以组员的现代化 React 18 + Tailwind 适老界面为**第一交互门面**（外修温润普惠），在机构模式折叠区深度嵌入用户自研的**业内级计量经济学学术资产**（内炼硬核学术）。同时建立双模双向穿透路由，兼顾大创赛跨学科评委（商科/技术/金融）的全面诉求。

## 2. 用户场景与故事 (User Scenarios & Stories)

### User Story 1 - 银发长者与大众投资者视角 (Priority: P0)
作为一名长者或偏好稳健理财的普通投资者，我希望进入系统时默认看到温暖、安心、通俗易懂的界面：包含“资产安全评级 AAA”、“半圆彩虹晴雨表”、“稳健资产配置环形图”以及“为什么留现金”的贴心释疑，无需理解复杂的量化公式即可建立对防守能力的信任。

### User Story 2 - 金融工程与计量经济学专家评委视角 (Priority: P0)
作为大创赛金融评审专家（两院院士/高校博导/量化基金经理），我希望在点击顶部的“机构量化研报模式”或展开底部研报层时，能够直接核验其背后的计量经济学理论深度：
- 看到经典的 **Fama-MacBeth 滚动两阶段截面回归**（含市场 MKT、规模 SMB、价值 HML、动量 MOM 的 $\beta$ 系数、Newey-West HAC 异方差自相关稳健 t 值与 p-Value）；
- 看到标的特征与 **国泰安 (CSMAR) / Wind** 商业金融数据库的学术字段映射规范；
- 能够随时点击“进入完整机构看板”，穿透到底层 160+ 标的的逐日 K 线、时空图谱与深度回测中。

### User Story 3 - 离线路演与网络容灾场景 (Priority: P1)
作为答辩路演人，在赛场无外网或网络不稳定的严苛环境下，我需要系统支持完全零依赖的纯静态单文件独立运行，图表首屏秒开，所有学术表格与收益走势 100% 完整渲染，不发生任何白屏或 CDN 加载错误。

## 3. 功能需求与验收标准 (Functional Requirements & AC)

### FR-1: 银发安心理财助手主界面融合
- **AC 1.1**：保留组员优秀的 React 18 + TS + Tailwind CSS 3 视觉系统与温暖摄影 Hero Banner。
- **AC 1.2**：资产健康晴雨表采用原生纯数学 SVG 半圆多彩仪表盘（`HealthGauge`），展示市场温度与建议仓位。
- **AC 1.3**：收益曲线与配置环图采用 0 外部依赖的纯 SVG 矢量绘制（`EquityCurveChart`, `DonutChart`），提供悬浮数值对齐与“为什么留 36% 现金”折叠说明。
- **AC 1.4**：保留产业链避险小卫士动态卡片（情绪面监测、事件驱动超额、智能仓位调节）。

### FR-2: 业内级学术计量经济学面板注入
- **AC 2.1**：在底部「机构量化研报模式」中新增二级标签页控制（Tabs）：
  - Tab 1: **策略回测表现**（策略排名、净值多线对比、板块相关性矩阵）；
  - Tab 2: **学术因子与计量定价**（Fama-MacBeth 滚动两阶段回归实证表、CSMAR 原生数据源与学术字段映射表、BibTeX 学术文献引用）。
- **AC 2.2**：Fama-MacBeth 表格必须严格包含因子名称、$\beta$、t-Stat、p-Value 及经济学含义说明，支持 Newey-West 稳健标准误标识。
- **AC 2.3**：CSMAR 映射表准确标注因子变量、开源免费源、Wind 商业字段及国泰安 (CSMAR) 权威代码。

### FR-3: 双模双向穿透与路由打通
- **AC 3.1**：新首页顶部胶囊按钮支持“普惠理财通模式（默认）”与“机构量化研报模式”一键切换；
- **AC 3.2**：点击“机构量化研报模式”时，平滑滚动并展开底部硬核计量区，同时提供“穿透至 A 股智能量化投研看板 ↗”按钮；
- **AC 3.3**：原量化看板 `index.html` 顶部固定返回入口：“← 返回银发安心理财首页”，实现双向完整闭环。

### FR-4: 单文件离线封箱与静态容灾
- **AC 4.1**：提供自动化打包脚本，一键将整合后的新前端编译打包为单文件 `docs/index_wealth.html`（内联全量 CSS、JS、SVG、插画与同构保底数据），文件大小严格控制在 500KB 以内。
- **AC 4.2**：无网络连接或无法访问后端 API 时，前端自动透明回退至经过校验的同构学术数据快照，控制台无致命报错，页面 100% 渲染完整。

### FR-5: 代码提交与 GitHub 同步
- **AC 5.1**：保持主工程 Git 树整洁，所有改动符合团队质量门禁；
- **AC 5.2**：合并产物、规格文档与测试用例完整提交，并同步推送至 GitHub 远程仓库 `origin/main`。
