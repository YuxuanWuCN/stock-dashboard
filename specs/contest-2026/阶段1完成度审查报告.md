#### 问题3：波动率调整逻辑阶梯化

```python
if volatility < 0.02: return 1.1
```

**问题**：阈值附近跳变（0.0499→1.0, 0.0501→0.8）

**修复方案**：
```python
def _calculate_volatility_adjustment_smooth(volatility, cfg):
    """平滑波动率调整（线性插值）。"""
    if volatility < cfg.volatility_low_threshold:
        return cfg.volatility_low_adj
    elif volatility >= cfg.volatility_high_threshold:
        return cfg.volatility_high_adj
    else:
        # 线性插值：[low_threshold, high_threshold] -> [low_adj, 1.0]
        # 或 [low_threshold, high_threshold] -> [1.0, high_adj]
        t = (volatility - cfg.volatility_low_threshold) / \
            (cfg.volatility_high_threshold - cfg.volatility_low_threshold)
        return cfg.volatility_low_adj + t * (1.0 - cfg.volatility_low_adj)
```
