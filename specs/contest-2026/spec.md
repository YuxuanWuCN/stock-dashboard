# 功能规格：Rainbow-FinGPT 策略增强与学术创新

**功能编号**：contest-2026  
**创建日期**：2026-09-01  
**状态**：规划中  
**优先级**：高

## 概述

对 Rainbow-FinGPT 系统进行两个维度的提升：
1. **策略增强**：改进 Alpha 因子质量、优化 Fama-MacBeth 定价模型、增强 Trend Gate 风控机制
2. **学术创新**：引入论文级别的方法论创新，提升系统的学术价值和技术壁垒

## 背景与动机

**当前系统状态**：
- 解耦三引擎架构：SCNU-RAG（定性）+ Fama-MacBeth（定价）+ Trend Gate（风控）
- 三板块实证：存储（Sharpe 2.51）、黄金（Sharpe 1.67）、绿电（Sharpe 未知）
- 核心技术：NALE 网络传导、252日滚动 Carhart 四因子、ZigZag 趋势状态机

**提升动机**：
- 校赛提交完成后，准备省赛/国赛更高要求
- 提升系统的学术创新性和技术深度
- 改进策略稳定性和超额收益能力

## 功能需求

### 2. 策略增强（Strategy Enhancement）

#### 2.1 Alpha 因子质量提升
- **需求**：提升从 LLM 语义特征中提取的 Alpha 因子的显著性和稳定性
- **当前问题**：
  - 立新能源案例：涨幅 +82.36% 但 Alpha p-value = 0.3543（不显著）
  - 因子 IC（信息系数）衰减问题
  - 语义特征到定价信号的传导效率
- **期望改进**：
  - 引入因子正交化处理，剥离风格暴露
  - 增加因子衰减检测与自适应权重调整
  - 探索多时间尺度因子融合（日度/周度/月度）

#### 2.2 Fama-MacBeth 定价模型优化
- **需求**：优化两阶段回归的稳健性和预测能力
- **当前实现**：252日滚动窗口 + Newey-West HAC 修正
- **期望改进**：
  - 动态窗口选择（基于市场状态/波动率调整）
  - 引入时变风险溢价估计（regime-switching 框架）
  - 增加非线性定价关系捕捉（GAM/spline 扩展）

#### 2.3 Trend Gate 风控机制增强
- **需求**：提升极端行情下的风险控制能力
- **当前实现**：MA20 + MACD + 艾略特 C 浪排斥
- **期望改进**：
  - 引入宏观状态机（牛市/熊市/震荡识别）
  - 增加流动性风险监控（成交量萎缩预警）
  - 动态仓位管理（根据市场状态调整暴露度）

### 7. 学术创新（Academic Innovation）

#### 7.1 方法论创新方向探索
- **候选方向 A**：因果推断框架
  - 引入 Granger 因果检验验证因子-收益因果链
  - 使用 do-calculus 框架建模干预效应
  - 构建因果图谱（causal graph）可视化定价机制
  
- **候选方向 B**：强化学习动态调仓
  - 将组合管理建模为 MDP（马尔可夫决策过程）
  - 使用 PPO/SAC 学习最优调仓策略
  - 引入 offline RL 避免样本外过拟合
  
- **候选方向 C**：图神经网络增强 NALE
  - 用 GCN/GAT 替代简单邻接矩阵传导
  - 学习异质图上的注意力权重（上下游/竞争/合作关系）
  - 动态供应链拓扑更新机制
  
- **候选方向 D**：不确定性量化与贝叶斯推断
  - 为 Alpha 预测增加置信区间（Bayesian Fama-MacBeth）
  - 引入 MCMC/变分推断估计参数分布
  - 基于不确定性的仓位sizing（Kelly准则扩展）

#### 7.2 学术产出目标
- 形成可发表的技术报告或论文草稿
- 构建完整的方法论白皮书
- 准备省赛/国赛的学术答辩材料

## 非功能需求

### 性能要求
- 策略优化不应显著增加回测耗时（<20% 增长）
- 新增模型需支持增量更新（避免全量重算）

### 可维护性
- 新增模块需遵循现有三引擎解耦架构
- 保持 pytest 测试覆盖率 >90%
- 所有创新点需有对应的学术文献溯源

### 验证标准
- 样本外回测 Sharpe Ratio 提升 ≥10%
- 最大回撤降低 ≥5个百分点
- 至少一个学术创新点通过同行评审（教师/专家反馈）
