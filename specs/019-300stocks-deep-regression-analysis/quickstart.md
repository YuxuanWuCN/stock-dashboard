# 快速上手：300 支标的 Fama-MacBeth 深度回归分析

本文档指导如何在本地一键复现并运行 300 支标的深度回归分析，用于团队内部研讨与答辩材料准备。

---

## 🚀 1. 一键执行命令

在仓库根目录下运行：

```bash
# 执行 300 支全池标的深度两阶段回归
python scripts/run_300stocks_deep_regression.py
```

执行后预计在 5~10 秒内完成全量计算并生成所有报告。

---

## 📂 2. 生成的核心交付物一览

所有分析成果保存在 `reports/tables/regression_300stocks/`：

1. **`stage1_stock_alphas.csv`**  
   包含全部 300 支股票的年化 Alpha、t 统计量、p 值、信息比率 (IR)、四因子 Beta 暴露向量 (`MKT`, `SMB`, `HML`, `MOM`) 及分类标签 (`True Alpha` / `Pure Beta`)。
2. **`stage2_factor_premia.csv`**  
   阶段二 Fama-MacBeth 因子风险溢价统计表（含年化溢价、FM 标准误、t 统计量、显著性检验结果）。
3. **`cohort_regression_summary.csv`**  
   分派给三位同学的各 100 支标的组别指标对比汇总（硬科技 vs 周期资源 vs 大金融消费）。
4. **`fama_macbeth_regression_report.md`**  
   完整的学术级分析报告与组员开会研讨指南。

## 💡 3. 如何向组员讲解这套回归分析？

1. **解释为什么要做回归**：  
   单纯看某只股票涨了多少没有意义（那可能是由于大盘好，即高 $\beta$）。我们用 Fama-MacBeth 回归把大盘行情 (`MKT`)、小盘效应 (`SMB`)、价值溢价 (`HML`) 和动量惯性 (`MOM`) 全部扣除后，剩下的截距项 $\alpha$ 才是系统模型与因子的“真实本领”。
2. **向同学 A 展示硬科技组**：  
   科技股平均 Beta 达 1.19，弹性大；True Alpha 标的（如宁德时代、香农芯创、寒武纪）年化 Alpha 超 60%，但非系统性波动较大，需要高频资金流因子压降回撤。
3. **向同学 B 展示周期与绿电组**：  
   价值因子载荷最高，京能电力、派能科技、龙源电力表现出高显著性 Alpha，抗通胀和稳健防守价值显著。
4. **向同学 C 展示大金融与消费医药组**：  
   True Alpha 占比最高（达 30%），平均信息比率 $IR=0.84$ 居三大组之首，平安银行、东鹏饮料、迈瑞医疗具备强大的安全边际。
