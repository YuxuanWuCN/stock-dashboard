# 规范: 008-monster-gated-portfolio (妖股鉴定器与市场温度联动模拟盘)

## 1. 概述与业务目标
本项目旨在解决股票分析系统在真实交易中的两大核心痛点：
1. **股票性质认知不明确**：无法快速识别高波动/游资题材炒作型标的（妖股）与稳健趋势型标的的差异，导致短线博弈与中长线配置策略错配。
2. **缺乏宏观择时与风控**：回测显示传统策略在弱市阴跌环境中强制满仓，导致回撤高达 28%~40%。

通过引入 **【股票性质分辨器 · 妖股鉴定器】** 与 **【大盘市场温度与动态仓位门控】**，实现：
- 200 只 A 股的四维度性质分类（🔥 妖股题材型 / 🎯 趋势主升型 / 🧱 震荡蓄势型 / 🛡️ 稳健防御型）
- 基于大盘温度（极寒/偏冷/正常/活跃）自动调节总股票仓位与现金比例
- 在 Web 看板提供直观的性质诊断卡与 60 天长跑回测对比曲线

---

## 2. 用户故事与需求

### User Story 1 (P1): 妖股鉴定与股票性质分类系统
- **作为** 投资者
- **我希望** 可以在看板上查看任意股票的性质画像（妖股指数、年化波动、ATR比例、动量半衰期）及专属操盘建议
- **以便于** 针对高弹性妖股采取极短线快进快出，对趋势股采取中线持有策略。

### User Story 2 (P1): 市场温度动态仓位与严谨风控引擎
- **作为** 量化操盘者
- **我希望** 模拟盘能够根据全市场温度自动降仓（如弱市保留 75% 现金），并具备单股 -8% 严格止损与浮盈回撤锁定利润机制
- **以便于** 在大盘杀跌周期有效防守，将最大回撤控制在 20% 以内。

### User Story 3 (P2): 前端模拟盘呈现与交互整合
- **作为** 看板用户
- **我希望** 在主看板（index.html）和组合页（portfolio.html）中直接查看 60 天长跑回测对比图表、实时持仓与温度仓位建议
- **以便于** 获得一体化、清晰专业的研究决策支持。
