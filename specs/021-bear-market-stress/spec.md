# 规范文档：熊市压力测试中 T-NALE 与 Risk-Constrained NALE 信号隔离与时效复用修复

**项目**：Rainbow_FinGPTv2  
**功能标识**：`021-bear-market-stress-fix`  
**关联分支**：`fix/real-data-rebuild`  
**对应工件目录**：`specs/021-bear-market-stress/`  

---

## 1. 背景与缺陷定位

在 `reports/fof_stress_20261014/bear_stress_report.md` 中，历史窗口策略对照表显示 `risk_constrained_nale` 与 `t_nale` 的全部量化指标（年化收益率、最大回撤、夏普比率、总换手率、交易费用、平均卫星仓位）完全一致。

**根因分析**：
1. **信号源未分化**：`scripts/run_bear_market_stress.py` 中的 `generate_signals` 函数使用固定种子生成均匀分布随机数，并未区分 `risk_constrained_nale`（静态 NALE）与 `t_nale`，导致输入两者的原始分数序列完全一致。
2. **标量时效衰减在截面归一化中完全对消**：`src/portfolio/backtest.py` 中的 `_apply_t_nale_decay` 仅接收标量半衰期（默认 5.0 天），且因未传入动态年龄映射，所有卫星标的的信号年龄均退化为默认值 1 天。在 `FOFAllocator._rank_standardize` 计算正向主动偏离比例时，所有标的分数同时乘以常数 $0.5^{1/5}$，分子分母同乘常数导致标量因子在截面相对归一化时完全约去，最终生成的卫星组合配置权重与静态 NALE 完全重合。
3. **敏感性分析模式串错位**：在 `run_param_sensitivity` 中，针对半衰期维度测试时，回测引擎模式被硬编码为 `"risk_constrained_nale"` 而非 `"t_nale"`，导致时效半衰期网格测试实际未执行时效衰减分支。

## 2. 需求规范范围（严格限定五项）

### REQ-1：T-NALE 模式与静态/Risk-Constrained NALE 模式的信号与配置隔离
- **REQ-1.1**：在输入相同行情时，`t_nale` 模式必须生成与 `risk_constrained_nale`（静态 NALE）具备截面差异的点时信号序列。
- **REQ-1.2**：回测引擎在调仓日计算得出的卫星资产目标配置权重矩阵，`t_nale` 与 `risk_constrained_nale` 在至少一个交易日存在实质性非零偏离（$\sum |w_{t\_nale} - w_{static}| > 10^{-4}$）。
- **REQ-1.3**：模式标识必须单向严格绑定，禁止将 `t_nale` 内部别名映射或静默回退至 `risk_constrained_nale`。

### REQ-2：异质半衰期与节点年龄时效逻辑的可追溯复用
- **REQ-2.1**：复用普通 FOF 回测流水线（`tools/run_fof_pipeline.py`）中的异质行业先验半衰期定义（如芯片/存储 12天、光伏/新能源 8天、黄金 3天、医药 15天、白酒/消费 10天、科创50 4天等），不重新发明或随意更改半衰期模型。
- **REQ-2.2**：时效衰减基于点时滚动收益计算的符号极性切换动态追踪节点信息年龄（`node_ages`），或者点时因果推断信息年龄，使各行业在截面上的衰减速度分化。
- **REQ-2.3**：提取或规范化时效衰减纯函数，支持传入字典形式的标的异质半衰期与动态年龄，确保时效衰减在截面加权时不再被约去。

### REQ-3：无未来函数与严格点时输入（Point-in-Time）
- **REQ-3.1**：所有信号生成与节点年龄计算只能使用截至交易日 $t-1$ 的历史行情数据，严禁在 $t$ 日使用当日收盘价或未来数据。
- **REQ-3.2**：截断不变性验证：向回测区间末尾追加未来 $k$ 个交易日的行情数据，历史时点 $t \le T_0$ 处的各标的信号得分、节点年龄及分配权重必须保持逐位不变。

### REQ-4：既有历史回测产物不覆盖（Immutable History）
- **REQ-4.1**：严禁覆盖或修改 `reports/fof_rebuild_20261013/` 下的任何基准产物。
- **REQ-4.2**：严禁覆盖或物理删除 `reports/fof_stress_20261014/` 下的既有历史压力测试结果，以保留故障发生时的原始对比证据。
- **REQ-4.3**：修复后的熊市压力测试输出默认写入指定的新修订目录 `reports/fof_stress_20261014_fixed/` 或明确的带时间戳目录。

### REQ-5：回归测试与独立结果复核
- **REQ-5.1**：编写端到端单元测试覆盖：
  1. 静态 NALE 与 T-NALE 产生截面差异有效信号与权重；
  2. 模式参数不会将 T-NALE 静默映射为 risk_constrained_nale；
  3. 追加未来数据不改变历史信号与权重（截断不变性）；
  4. 产物目录隔离，不污染旧目录。
- **REQ-5.2**：独立复核：计算指标由独立向量化算法复核；不为了“让结果好看”而微调半衰期或任何超参数，即使 T-NALE 在特定熊市窗口表现弱于静态 NALE，也必须如实记录。
