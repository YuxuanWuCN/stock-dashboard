## 数据勘察结论（Phase 0）

### 1. K线数据（docs/data/kline/001258.json）

- 结构：`{code, name, type, adjust: qfq, dates[], kline[], volume[], ma5[], ma10[], ma20[], ma60[]}`
- **列序确认为 [开, 收, 低, 高]**（ECharts candlestick 顺序）——此前误读为 [开, 高, 低, 收] 造成假性异常，已澄清无需修复
- 268 根日K，2025-07-09 ~ 2026-08-13，前复权（qfq）
- 校验：无异常K线（low ≤ min(open,close) ≤ max(open,close) ≤ high 全通过）

### 2. 市场温度（情绪因子候选）

- `docs/data/strategy/market_temperature.json`：**单时点快照**（generated_at 2026-08-13，temperature 51.0，status 偏冷）
- `docs/data/strategy/market_temperature_history.json`：**仅 2 条**（08-12: 88.0, 08-13: 51.0）
- **结论：市场温度历史不足，不能作为全序列情绪因子**

### 3. 市场情绪快照（reports/market_sentiment/sentiment_2026081{1,2,3}.json）

- 3 天快照：market_data（涨跌家数/平均涨跌/涨停数）+ news + sentiment_analysis
- **同样只有 3 天，不能做全序列**

### 4. 情绪因子降级方案

- 全序列情绪代理改用**量价指标**（可从头算满 268 天）：
  - 成交量放大倍数（vs 20日均量）→ 资金热度
  - 涨停后次日溢价/高开幅度 → 情绪强度
  - 5日波动率/ATR → 情绪亢奋度
  - 乖离率（BIAS，收盘价 vs MA20）→ 过度偏离
- 市场温度（2点）作为**当前时点注脚**（08-13 温度 51 偏冷），不参与全序列

- 项目内无流通市值数据（analysis JSON 无市值字段）
