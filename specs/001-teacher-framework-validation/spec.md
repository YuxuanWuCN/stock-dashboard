**Feature Branch**: `001-teacher-framework-validation`

**Created**: 2026-08-14

**Status**: Draft

## Clarifications

### Session 2026-08-14

- Q: 回测范围是单独研究报告还是顺带修改激进策略代码？ → A: 先研究后改进。本次 feature 只做验证报告，不修改 src/strategies/；若老师认可规则，另开 feature 将"翻倍减仓"写进激进策略（走质量门禁）
- Q: "减到还有一点"具体保留多少仓位？ → A: 保留 1/3（B组减到三分之一）
- Q: 翻倍确认后按什么价格成交？ → A: 次日开盘价（触发日收盘确认，下一交易日开盘成交）
- Q: 07-28/07-29 K线数据异常怎么处理？ → A: 核实后确认数据无异常——K线列序为 [开, 收, 低, 高]，最初按 [开, 高, 低, 收] 误读导致假性异常。无需修复，无需重新拉取。07-28 实为 -9.98%（盘中冲高 15.73 后收 12.90），07-29 为 -10.00%，两天累计约 -19%
- Q: 回测的"翻倍"以什么为基准参照点？ → A: 滚动低点翻倍：本轮行情起点 = 过去 60 个交易日最低收盘价，收盘价首次达到起点的 2.0 倍即触发；触发后需创新低才重置。立新能源历史上唯一触发点：2026-07-24（收盘 13.03，相对 07-13 低点 6.49 涨幅 +100.8%）

## 背景 (Background)

本项目用户（学生）在与经济学老师的对话中，就立新能源（001258）的走势获得了一段口头分析。老师提出了四个层次的判断：

1. **事实判断**："短期上涨了一倍"、"市值规模小，一百多个亿"
2. **状态判断**："处于业务成绩兑现期"、"现在位置风险较高"
3. **机制判断**："市值小 → 资金炒作拉起来容易，下去也容易"；"规模、资金、行业和情绪都很重要"（四因子框架）
4. **操作/预测判断**："已获利建议减仓，不宜追高"；"回调是早晚的事情"

本 feature 的目标：把这段口头分析翻译为**可验证的规则**，用立新能源的历史数据逐条验证，产出对比报告。报告的用途是**与老师的第二次对话**——用数据展示执行力，并把话题从"怎么操作"升级为"为什么同样规则在不同时期表现不同"的研究问题。

**范围界定（澄清 Q1）**：本次 feature 只做验证研究报告，不修改 src/strategies/ 下的任何策略代码。若验证结果获老师认可，另行开启新 feature 将"翻倍减仓"规则写进激进策略（届时走质量门禁流程）。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 核验老师的事实判断（翻倍与市值规模） (Priority: P1)

学生拿到老师口头分析后，先验证其中可查证的事实部分，确认后续分析建立在准确数据之上。

**Why this priority**: 所有后续验证都以"翻倍"为前提。若事实核验有偏差，整份报告的可信度崩塌；这是 P1 的地基。

**Independent Test**: 仅用立新能源历史K线数据和市值快照即可完成，输出"翻倍事实成立/不成立"的结论，独立交付价值（学生可以立即确认老师说得对/不对）。

**Acceptance Scenarios**:

1. **Given** 立新能源 268 根日K线（2025-07-09 ~ 2026-08-13，列序 [开, 收, 低, 高]），**When** 计算 7 月行情涨幅，**Then** 输出两个口径：①连板行情起点 07-16 收盘 7.42 → 07-28 盘中高 15.73，盘中涨幅 +112%（翻倍成立）；②滚动 60 日低点口径：07-13 低点 6.49 → 07-24 收盘 13.03，收盘价口径 +100.8%（翻倍成立）。明确标注 07-28 收盘 12.90（未翻倍）——盘中翻倍当日即回落至跌停价
2. **Given** 同一数据源，**When** 计算截至最新交易日（2026-08-13）的累计涨幅与距离最高点的回撤，**Then** 输出当前涨幅（相对 07-13 低点）与当前回撤（相对 07-28 盘中高 15.73）
3. **Given** 项目内无市值数据，**When** 查询立新能源最新流通市值，**Then** 优先尝试项目现有数据源核验"一百多亿"；若不可得，明确标记"未验证"而不是编造数字

### User Story 2 - 回测"翻倍触发"后清仓/减仓/持有三组对照 (Priority: P1)

把老师的操作建议（"已获利建议减仓位，不宜追高"）翻译为三组对照实验：以滚动低点翻倍为触发条件，比较"清仓（减到没）/ 减仓保留三分之一（减到还有一点）/ 持有不动（对照组，激进策略的实际行为）"。

**Why this priority**: 这是老师原话中唯一可操作的部分，也是第二次对话的核心素材——用数据检验老师的建议，无论结果支持或部分否定老师的建议，都能引出一个有质量的研究问题。

**Independent Test**: 只用K线数据即可独立回测，输出触发点之后三种操作的收益对比表，独立交付。

**Acceptance Scenarios**:

1. **Given** 滚动 60 日低点翻倍触发规则（收盘价首次达到行情起点 2.0 倍），**When** 扫描 268 根K线，**Then** 输出全部触发日及基准点。预期找到唯一触发点：2026-07-24（收盘 13.03，基准 07-13 低点 6.49，+100.8%）
2. **Given** 触发日 2026-07-24，**When** 以次日（07-25）开盘价 13.02 模拟成交，**Then** 输出三组策略在 5/10/20 日窗口的收益：A=触发次日全清仓、B=触发次日减至三分之一仓（保留 1/3 继续持有）、C=持有不动（对照组）
3. **Given** 三组窗口收益，**When** 计算各组 20 日窗口的最终收益率及最大回撤，**Then** 输出对比，明确指出哪一组躲过了 07-28/07-29 两日连续跌停（-9.98%、-10.00%，累计约 -19%）
4. **Given** 用户激进组合的实际行为（08-07 买入立新能源，当前仍持有），**When** 对照老师的规则，**Then** 在报告中标注"按老师规则 08-11 收盘 15.93（相对 07-13 低点 +145%）已超翻倍阈值，应减仓"与激进组合实际行为的差异，作为规则应用示范
5. **Given** 项目红线（研究信号仅供参考），**When** 生成报告，**Then** 所有对比以历史统计表述，不构成对当前持仓的操作指令

### User Story 3 - 验证"回调是早晚的事情" (Priority: P2)

把老师的预测（"回调是早晚的事情"）翻译为统计问题：历史上涨停/翻倍之后，回调（从阶段高点回落≥某阈值）发生的天数分布和幅度分布。

**Why this priority**: 这是老师的预测性判断，可事后验证。统计结果既能展示"老师的经验有数据支持"，也能引出更深的问题——如果回调必然发生，为什么还有人在那个位置买入？

**Independent Test**: 只用K线数据即可独立完成，输出"涨停后首次回调的等待天数与回调幅度"分布表，独立交付。

**Acceptance Scenarios**:

1. **Given** 9 次涨停事件及之后的价格路径，**When** 定义回调为"从涨停后窗口内最高点回落 ≥10%（幅度可配置，默认10%）"且窗口为 20 个交易日，**Then** 输出每次事件是否发生回调、回调发生的等待天数、回调幅度
2. **Given** 全部回调事件，**When** 统计等待天数和回调幅度的分布（中位数、最值），**Then** 输出分布摘要，回答"回调通常多久来、通常多深"
3. **Given** 2026-08-13 之后数据缺失（样本外），**When** 生成报告，**Then** 把 08-11 涨停后的走势标注为"进行中，未验证"，严禁用未来数据回填

---

### User Story 4 - 用四因子框架构建风险评分并回测预警能力 (Priority: P2)

老师提出"规模、资金、行业和情绪都很重要"。把这四个词翻译为可计算的代理变量，构建立新能源的历史风险评分曲线，检验高分区间是否真的对应后续大跌（尤其是 07-28/07-29 两日连续跌停，累计约 -19%）。

**Why this priority**: 这是老师原话中最有学术价值的部分——一个可扩展的四因子分析框架。验证它既是对老师框架的落地，也是把对话升级为"研究合作"的关键素材（学生需要知道哪些因子有数据、哪些因子缺数据）。

**Independent Test**: 用项目已有的数据（K线、成交量、市场温度）独立构建四因子中的三个（规模、资金、情绪），行业因子标注缺数据，输出风险评分曲线与暴跌事件的对应关系，独立交付。

**Acceptance Scenarios**:

1. **Given** 老师四因子框架，**When** 翻译为代理变量，**Then** 输出四因子操作化定义表：规模=流通市值（小市值高波动风险，数据待核验）、资金=成交量放大倍数与涨停封单强度（游资炒作热度）、行业=电力/新能源板块相对强度（缺数据需标注）、情绪=市场温度四因子读数（已有数据）
2. **Given** 代理变量历史序列，**When** 计算每日风险评分（0-100），**Then** 输出风险评分曲线与关键事件标注（9 次涨停、07-28/07-29 连续跌停）
3. **Given** 风险评分曲线，**When** 检验"高分区间是否领先于大跌"，**Then** 输出"跌停前N日风险评分 vs 其他时期风险评分"的对比（例如 07-28 前 5 日均值 vs 全样本均值）
4. **Given** 行业因子数据源缺失，**When** 生成报告，**Then** 明确标注"行业因子未验证"，并列出可补充的数据源（如板块指数、行业ETF行情）作为向老师请教的问题之一

### User Story 5 - 生成面向老师的第二次对话报告 (Priority: P3)

汇总全部验证结果，输出一份可读的对比报告：老师的判断哪些被数据支持、哪些部分成立、哪些当前无法验证，并提炼 2-3 个研究问题用于第二次对话。

**Why this priority**: 这是全部工作的交付形态，但依赖前四个 story 的结果，因此优先级最后。

**Independent Test**: 前四个 story 全部完成后，报告可由脚本一次生成；人工检查报告包含"验证结论表 + 研究问题清单"即可验收。

**Acceptance Scenarios**:

1. **Given** 全部验证结果，**When** 生成报告，**Then** 报告包含：老师原话 → 翻译规则 → 验证结果 → 支持/部分支持/未验证分类表
2. **Given** 验证中发现的"规则在3月失效、7月有效"类差异，**When** 提炼研究问题，**Then** 输出至少 2 个可向老师请教的问题（例如"同样的回调模式为何在不同市场温度下表现不同""小市值涨停股的风险是否可用四因子提前量化"）
3. **Given** 报告生成，**When** 检查文件输出位置，**Then** 报告保存至 reports/ 目录（与项目报告规范一致），并附上第二次对话的开场话术建议

---

### Edge Cases

- 触发次日若为跌停开盘无法卖出（如 07-28 后 07-29 开盘即 -10%），模拟成交价按次日实际开盘价，并标注"实际可能无法以该价格成交"
- 数据中的异常K线必须按正确列序 [开, 收, 低, 高] 解读（此前误读导致假性异常，已澄清无需修复）
- 2026-08-13 之后的验证窗口尚未走完，所有涉及未来数据的统计必须截断到 2026-08-13
- 市值数据若无可靠来源，必须标注"未验证"，禁止用估算值充当实测值
- 报告不得给出投资建议（项目红线：研究信号仅供参考），所有结论以"历史统计"表述

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 核验"短期翻倍"事实：输出连板口径（07-16→07-28盘中高，+112%）与滚动低点口径（07-13→07-24收盘，+100.8%）两个涨幅，并判定是否 ≥100%
- **FR-002**: 系统 MUST 实现滚动 60 日低点翻倍触发规则（收盘价首次达行情起点 2.0 倍即触发，创新低重置），扫描输出全部触发日
- **FR-003**: 系统 MUST 在触发日次日开盘价模拟三组操作：A=全清仓、B=减至三分之一仓（1/3 保留继续持有）、C=持有不动（对照组），并计算 5/10/20 日窗口收益
- **FR-004**: 系统 MUST 输出三组操作的 20 日最大回撤对比，明确是否躲过 07-28/07-29 连续跌停（累计约 -19%）
- **FR-005**: 系统 MUST 统计涨停后 20 日内回调（自高点回落 ≥10%，阈值可配置）的发生率、等待天数分布、回调幅度分布
- **FR-006**: 系统 MUST 输出截至 2026-08-13 的价格位置注脚：现价相对 MA5/MA10/MA20 的位置、距前高（15.73）回撤
- **FR-007**: 系统 MUST 实现四因子风险评分（0-100）：规模因子（市值量级，标注数据可得性）、资金因子（量能/涨停强度）、行业因子（标注缺数据）、情绪因子（市场温度），并生成每日风险评分序列
- **FR-008**: 系统 MUST 检验风险评分对 07-28/07-29 连续跌停的预警关系（跌停前5日均分 vs 全样本均分对比）
- **FR-009**: 系统 MUST 标注激进组合实际行为（08-07 买入仍持有）与老师规则（08-11 已触发翻倍应减仓）的差异，作为规则应用示范
- **FR-010**: 系统 MUST 生成第二次对话报告，包含：验证结论分类表（支持/部分支持/不支持/未验证）、至少2个研究问题、对话开场话术建议，保存至 reports/ 目录
- **FR-011**: 所有涉及未来数据的统计 MUST 截断到 2026-08-13；进行中的验证（08-11 后）MUST 标注"未验证"
- **FR-012**: 报告 MUST 遵守项目红线：只呈现历史统计，不构成投资建议

### Key Entities

- **行情起点 (Run Low)**: 过去 60 个交易日最低收盘价，翻倍触发规则的基准点；属性：日期、价格
- **翻倍触发点 (Double Trigger)**: 收盘价首次达到行情起点 2.0 倍的交易日；属性：日期、触发收盘价、基准点、涨幅、次日开盘价
- **操作策略 (Action Policy)**: 触发后的应对，三种：A=全清仓、B=减至三分之一仓、C=持有不动；属性：入场日（触发次日）、窗口期（5/10/20日）、窗口收益、最大回撤
- **回调事件 (Pullback Event)**: 从窗口内最高点回落 ≥10%；属性：发生与否、等待天数、回调幅度
- **四因子风险评分 (Risk Score)**: 每日 0-100，属性：规模/资金/行业/情绪四分量及合计
- **市场温度 (Market Temperature)**: 项目已有数据（advance/decline 等四因子读数），作为情绪因子的数据源
- **验证报告 (Validation Report)**: 汇总实体，属性：验证结论表、研究问题清单、对话话术

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 翻倍事实核验输出明确结论（成立/不成立），并给出两个口径的精确涨幅百分比
- **SC-002**: 翻倍触发扫描输出全部触发日；三组操作在全部触发点上的窗口收益计算完成，无遗漏
- **SC-003**: 回调统计输出"发生率 + 等待天数中位数 + 回调幅度中位数"三项完整
- **SC-004**: 四因子风险评分曲线完整覆盖 268 个交易日，其中行业因子缺数据处明确标注
- **SC-005**: 跌停预警检验输出可对比的两个数字（跌停前5日均分 vs 全样本均分）
- **SC-006**: 报告含 ≥2 个研究问题、验证结论分类表（每个老师判断至少归类为 支持/部分支持/不支持/未验证 之一）、对话开场话术
- **SC-007**: 报告中无未来数据泄漏（所有统计截断至 2026-08-13），无编造数据（缺数据处显式标注）

## Assumptions

- 立新能源K线数据文件 docs/data/kline/001258.json 是准确的前复权日线数据，列序为 [开, 收, 低, 高]（已核实无异常K线，无需修复）
- "减仓"已澄清：B组减至三分之一仓（保留 1/3 继续持有）
- "翻倍"已澄清：滚动 60 日低点口径，收盘价首次达起点 2.0 倍触发
- 成交价已澄清：触发日收盘确认信号，次日开盘价成交
- 市值数据若项目内无存储，尝试现有数据源核验或标注"未验证"；不编造
- 市场温度数据（docs/data/strategy/market_temperature.json）可作为情绪因子代理
- 本次 feature 不修改策略代码（范围已澄清）；老师认可规则后再另开 feature 实施
- 本项目为研究验证用途，输出不构成投资建议（遵循项目红线）
